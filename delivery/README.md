# 交付目录：只分两份

你不需要逐个判断里面的文件，也不要拆开发送。

| 你要做的事 | 只用哪个文件夹 | 是否能发给部署人员 |
| --- | --- | --- |
| 找人给客户部署机器人 | `01-发给部署服务人员` 整个文件夹 | 可以，整个发出 |
| 发许可证、续费、保存客户记录 | `02-给项目所有者` 整个文件夹 | 不可以，只自己保留 |

给部署人员时，只发送 `01-发给部署服务人员` 这个完整文件夹。他们从里面的
`README.md` 开始，再进入 `客户部署包` 双击部署脚本。里面的源码、迁移文件和
配置文件是脚本运行必需的，不需要让部署人员逐个阅读。

你自己从 `02-给项目所有者/README.md` 开始。该文件夹里的授权脚本、客户资料
模板和验收记录都只供授权方/销售管理员使用，绝不能发送给部署人员。

以下 4 项另用安全渠道发给部署人员：客户名称、管理员 Telegram 数字 ID、Bot
Token、该客户的授权密钥。不要发送 `.license-admin.env`、`LICENSE_ADMIN_TOKEN`、
你的 Cloudflare Token 或任何其他客户的密钥。
