# 项目所有者：发授权与交付

这份目录只给你自己保存，不能交给客户或部署人员。

## 第一次，只做一次

在厂商授权中心已经完成 Cloudflare 部署、D1 migration 和 Bot Secret 配置后，打开
Linux 终端并进入本目录，执行：

```bash
bash 00-初始化授权中心.sh
```

它会生成并保存厂商管理令牌，并写入厂商 Worker。令牌保存在项目根目录
`.license-admin.env`；它不能发送给任何部署人员或客户。以后需要作废旧令牌时，
运行 `bash 00-初始化授权中心.sh --rotate`。

## 每个客户，只需两步

1. 执行 `bash 01-一键发放授权.sh`，输入客户名称和天数。直接回车默认 365 天，输入
   `forever` 是永久授权。第一次如默认授权中心地址不对，粘贴你的 Worker 地址；
   下次会继续显示默认地址。
2. 脚本显示密钥后，只把“授权密钥”这一行发给部署人员；再把
   `delivery/01-发给部署服务人员/` 整个目录发过去。

部署人员还需要客户名称、管理员 Telegram 数字 ID、Bot Token。Cloudflare 登录由
客户在部署电脑完成。不要把厂商 Cloudflare Token、`.license-admin.env`、
`LICENSE_ADMIN_TOKEN` 或其他客户密钥发出去。

如果授权方本人使用 Windows，才使用同名 `.cmd` 文件；它们和 Linux 脚本做的是
同一件事。

## 部署完成后

收回部署人员提供的 `deployment-manifest.json` 和 Worker URL。用管理员账号测试：
`/start`、创建两题问卷、发布；再用普通账号测试 `/surveys` 和填写。把客户名、
授权编号、授权类型和部署清单保存在本目录的模板中。

## 续费或停用

日常续费可在厂商 Bot 中发送：

```text
/license_extend 授权编号 天数
/license_suspend 授权编号
/license_resume 授权编号
```

永久授权的升级权益使用 `/license_updates 授权编号 天数`。`/license_revoke` 不可
恢复，除非确认需要永久作废，不要使用它。
