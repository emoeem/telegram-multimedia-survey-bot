# 这是授权方/销售管理员专用文件夹

不要把这个文件夹发送给部署人员、客户或公开群聊。

日常只做两件事：

1. 授权中心首次启用时，在 Linux 终端运行 `bash 00-初始化授权中心.sh`。
2. 每个新客户，在 Linux 终端运行 `bash 01-一键发放授权.sh`，把脚本显示的授权
   密钥单独发给部署人员。

同名 `.cmd` 文件只给 Windows 授权方备用；你的 Linux 电脑不需要使用它们。

部署完成后，把对方回传的 `deployment-manifest.json`、客户资料和验收结果保存在
这里的模板中。完整说明见 [给项目所有者内部说明](给项目所有者内部说明.md)。
