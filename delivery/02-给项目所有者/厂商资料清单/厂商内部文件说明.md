# 厂商内部资料说明

本目录用于项目所有者自己保存，不要放进客户交付包。

## 必须保密

- `.license-admin.env`
- `LICENSE_ADMIN_TOKEN`
- 厂商 Cloudflare API Token
- 其他客户的许可证密钥
- 生产环境 `.dev.vars`
- 厂商生产 `wrangler.toml`

## 当前项目中的对应位置

```text
项目根目录/.license-admin.env
项目根目录/.dev.vars
项目根目录/wrangler.toml
```

这些文件都不应复制到：

```text
delivery/01-发给部署服务人员/
```

## 每个客户应单独保存

- 客户基本资料。
- 授权编号和许可证密钥。
- `deployment-manifest.json`。
- Worker URL。
- D1、KV、Queue 资源记录。
- 部署验收记录。
- 续费与升级记录。
- 客户专属问题和处理记录。

建议使用加密磁盘或密码管理器，不要把完整客户资料放在公开网盘。
