## 一句话梗概

梅雨季的午夜电台只读信、不回信——直到主播苏晚棠打破规则，私信了写信的人。这个夜晚往哪里走，由你决定；四种走法，四种她的回答。

## 角色与世界观

- **苏晚棠**，27 岁。深夜电台《午夜信箱》主播，声音低哑，惯用省略号；白天是出版社编辑，钢笔、冰美式，养一只叫「句号」的黑猫。
- **你**，28 岁。推理小说作者，失眠第三年，听众编号 0417。性别不做预设。
- **世界观**：南方城市，梅雨季。一档 00:00–02:00 的电台节目，规矩是「读信，不回信」。故事发生在一个雨夜之内。
- 所有角色均为成年人；故事中的亲密情节均以明确同意为前提，且每个节点都可以选择停下。

## 第 1 页 · 序章 · 雨夜频率

### N1 · note「第 214 期 · 午夜信箱」[配图：电台直播间，暖橙]

> 雨从傍晚下到现在。零点整，收音机里响起那段熟悉的垫乐，然后是她的声音——低哑，不紧不慢，像有人隔着毛玻璃念信。
>
> 「欢迎回到午夜信箱，我是晚棠。梅雨季的第七个夜晚，先说好，今晚不劝任何人早睡。」
>
> 你是听众 0417。三年来你给这档节目写过十一封信，全部石沉大海——规矩只有一条：读信，不回信。
>
> 今晚，她念完了你写的第十二封。然后，她停了两秒。
>
> 「这封信的末尾，有一个问题。……我不打算在电波里回答。」

>

## 第 5 页 · 深入线 ·「凌晨三点的语音条」

### N23 · note「线 · 六十秒」[配图：深夜窗帘与月光]

> 开场是声音。她说：「打字太快了。今晚我们换个规矩——我发语音条，六十秒一条。你只许用文字回。」
>
> 第一条，她什么都没说，只是把话筒凑近窗户，让雨声灌满整整六十秒。

### N27 · note「越过线的六十秒」[配图同场景，更暗]

> 那条语音条，四十七秒。
>
> 开头是她的呼吸，比垫乐里低半个调。她让你关灯，说「文字会发光」；她让你把手放在屏幕上，说「那里是我声音落下的地方」。
>
> 她讲得很慢。讲她念你的信时在哪里停顿、为什么停顿；讲她想象过写信的人握笔的样子。你回的字越来越少，最后一个字是她的名字——删了打，打了删，发出去的是「晚棠」两个字，没有称呼，没有句号。
>
> 她的回应是一条更长的语音条。内容你们两个人知道就好。只知道天快亮的时候，你数了数，那条六十秒，你循环了四十一遍。

## 问卷 JSON 生产映射

- 内容源：本剧本 → `scripts/galgame/galgame-survey.json`（UnifiedSurveyImport 形状，`schema_version: 1`）
- 节点：`note` = 剧情卡（title 场景名 / description 正文 / media 配图）；`single` / `yes_no` = 选择点（四选项并行长度）；`long_text` = 尾声（数组最后一题）
- 跳转：GATE 的 4 选项 → 各线首题（`condition.rules`，kind `option_equals`，D 线顺延）；同意节点「停下」→ 该线结局卡；线尾收束题 4 选项 → 全部指向尾声。JSON 内用 slug（如 `q-gate` / `o-gate-b`），导入脚本导入后回填数字 id（`condition_json` / `skip_to_question_id`）
- 媒体：JSON 内 `kv://<slug>` 占位，导入脚本写入 MEDIA_KV（`media:survey-galgame:<slug>`，temporary + expires_at NULL）后回填 `/api/survey/media/<id>`
- 主题：`settings_json` **直接存 theme 对象**（读取端形状），含 background / overlay / card / audio.byPage / completion.message
- 导入：`scripts/galgame/import_galgame_survey.py`（复用 wenai 导入器的参数化 helper），先 `--dry-run` 后 `--apply`
