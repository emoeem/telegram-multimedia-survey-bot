## 0. 结构与约定

### 0.1 四条线索

| 线索 | 触点（按叙事顺序）                                                                                                 |
| ---- | ------------------------------------------------------------------------------------------------------------------ |
| 雨夜 | 全景雨窗（底图）→ 01 窗 → 05 雨中的街 → 06 玻璃上的雨痕 → 07 雨的节拍 → 尾声题「雨快停了」→ 16 收束「雨停了」      |
| 旧信 | 02 桌上的信（写到一半）→ 09 唱机旁的信（没寄出的一摞）→ 15 暗格深处（按年份排好）→ 16 最后一封信（收信人是你）     |
| 旋律 | 03 留声机 → 07 雨的节拍（雨夜→旋律的桥）→ 08 转动的唱片（第七圈）→ 10 谱上的暗号 → 16 最后一封信（等有人接着听完） |
| 秘密 | 04 书架 → 10 谱上的暗号（旋律→秘密的桥）→ 11 夹着车票的旧书 → 13 书脊后的细缝 → 15 暗格深处 → 16「不再上锁」       |

### 0.2 叙事弧（起承转合）

- **起 · room 书房全景**：回到房间，一切如常，唯独桌上有封没写完的信。四条线索在这里各自埋下入口。
- **承 · window 窗前 / melody 唱机旁**：雨夜深化（街、雨痕），雨点节拍引向唱机；唱片停在第七圈，唱机旁摞着寄不出的信。
- **转 · shelf 书架深处**：褪色的旧书里夹着一张去海边的车票——一场没成行的旅行；书脊后的细缝露出暗格。
- **合 · closet 暗格 · 终章**：暗格开着，里面是所有没寄出的话；最后一封信把四条线索收拢——收信人是今夜推门进来的人。**收束热点 = `final-letter`（全局最后一个热点，meta 16）。**

### 0.3 底图与尺寸约定（设计决策）

- **全景底图恰好一张**：`kv://study-room/panorama`（1600×1000，供视频首帧）。五个场景共用它——
  概念是「一幅画，四个驻点」：场景切换不换画，换的是**驻足的位置**（标题 + 引导语 + 热点区域随之改变：
  窗前、唱机旁、书架深处、暗格）。全景的画里预埋了全部可点对象（雨窗、信、唱机、褪色的书、透光的细缝）。
- **内层图 8 张**（每个 image 热点一张）：1200×900 横构图 4 张（rain-street、record-spinning、ticket-book、
  hidden-open），1200×1600 竖构图 4 张（letter-desk、glass-rain、unmailed-letter、final-letter）。
- **kv 键 ↔ 资产 id ↔ 生成路径** 一一对应：`kv://study-room/<id>` ↔ asset-plan 的 `id` ↔ `study-room/art/<id>.png`。
- 全部画面对象在全景 prompt 中已定位（窗在左 1/3、书桌居中、唱机小几居右、书架右 1/3、细缝在书架右缘），
  热点归一化坐标与画面对象对齐。

### 0.4 其他约定

- `meta` 01–16 按叙事顺序编号，也是给参与者的隐式路径提示；实际探索顺序不限。
- 必答语义：场景题为必答题，至少探索一处热点才能进入下一题；尾声长文本选填。
- 全部图像无文字（prompt 已按统一前缀约定「无文字」；信、票、谱在画中只是模糊墨线/墨点质感）。
- 问卷 `anonymous: 0`（生产平台的注册墙为既有产品决策，见 `docs/guides/HOTSPOT_EDITOR_HANDOVER.md` §2）。

## 1. 问卷层文案

- **问卷标题**：雨夜书房 · 雨停之前
- **问卷描述**：一幅画，四个驻点，一夜的时间。点击画面里发亮的区域走进去看——雨夜、旧信、旋律、秘密，四条线索都藏在这间书房里；你走过的每一处都会记下来。
- **页**：p1「雨夜书房」
- **场景题（q-scene，必答）**
  - 标题：走进这幅画
  - 描述：下面是一间书房，也是一幅画。点击发亮的区域查看细节；有些区域会带你走到房间的另一个角落。雨夜、旧信、旋律、秘密——四条线索都从这里开始。
- **尾声题（q-farewell，选填 long_text，≤500 字）**
  - 标题：离开之前
  - 描述：雨快停了。走之前，留一句话给这间书房——给那封信、那支曲子，或者那个暗格（可以不填）。

## 8. 数量核对

- 场景 5 个（room / window / melody / shelf / closet），每场景热点 4 / 3 / 3 / 3 / 3；
- 热点共 16 个（image 8 + scene 8），≤24；id 全局唯一且满足 `^[a-z0-9][a-z0-9_-]{0,31}$`；
- 资产 9 张 = panorama 1 + inner 8（与 image 热点一一对应）；
- 引用完整性：配置里每个 kv:// 键都在 asset-plan 有同 id 条目；每张被引用的图都挂 `question.media`（= question_media）。
