## 一、PC：顶栏不再悬空

顶栏组件（PageHeader）此前一律给桌面主导航让位 56px（`lg:top-14`）——但投稿中心
**不渲染**主导航（广场/展示区才有），于是顶栏悬在半空，上面露出一条没有任何遮挡
的缝，滚动时表单内容从缝里穿过、又被半透明顶栏糊住，看起来「悬浮、中间缺一块」。

现在让位改为可选属性：带主导航的页面维持原样，投稿中心传 `false` 让顶栏贴住视口
顶部；同时顶栏内容列与表单列同宽对齐（此前标题在 1200px 宽列的左端、表单却居中，
两边对不上）。

## 二、手机：验证码输入框重见天日

提交按钮原先 `position: fixed` 悬在视口底部，靠给表单预留固定 padding 让位——但
按钮条的真实高度（字体缩放、safe-area、提示换行）永远算不准。生产实测（Playwright
390×844，滚到底）：验证码输入框 100% 被压在按钮条后面，`elementFromPoint` 点到的
是提交按钮——看不见、点不到。

改为 `position: sticky`：按钮条回到文档流，滚动中途它照样贴在视口底（观感不变），
滚到底它落在表单末尾的自然位置——验证码输入框完整露出，提交按钮就贴在最后一个
字段下面。顺带给验证输入框补了 `aria-label`。

两处都用 Playwright 对生产页做了修复前复现与修复后复检（顶栏 `top:0`、输入框
`hitIsInput: true`）。
