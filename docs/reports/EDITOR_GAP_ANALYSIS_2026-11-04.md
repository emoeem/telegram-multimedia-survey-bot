## 三、建议下一批（按 ROI 排序）

### P0 · 直接提升创作者与读者体验

1. **VN 播放器补齐**：backlog（历史对话）、跳过已读、自动播放、存读档多槽位。
   这是与 avg-engine 距离最直观、且对互动小说问卷最有价值的一组。
2. **Flag / 变量总览**：在体检里增加第二个页签，列出「谁产出、谁消费、最大分值」，
   并标出未使用 flag 与永远不触发的跳转（本轮已有 unknown-flag 检查）。
3. **预览继承状态**：从第 N 题预览时，允许先填几道前置题或模拟变量，走查
   条件分支时不用每次都从第一题开始。
4. **素材引用图**：媒体详情显示「被哪些题面/选项/主题引用」，反向定位缺失素材。

### P1 · 编辑效率

5. **在当前题之后插入**：物料区目前只追加到末尾；长问卷需要「在此后插入」。
6. **批量操作**：多选题目后批量必答/选答、批量移动分页、批量改题型。
7. **命令面板**：`Ctrl+K` 搜题、搜动作、搜模板，替代在左栏层级里找。
8. **脚本视图**：把题面/选项/跳转渲染成只读的类 Ren'Py 文本，供编剧通读与校对
   （先做只读，双向同步留到 P2）。

### P2 · 结构性能力

9. 多语言文案与玩家切换语言。
10. 多人实时协作与逐句历史。
11. 插件市场 + 扩展 SDK 文档。

## 四、本轮顺手修掉的问题

- **小游戏题属性面板崩溃**：`QuestionForm` 直接读 `response.packs.length`；
  接口返回异常形状时整张属性面板抛错，ErrorBoundary 把整个编辑器替换成错误页。
  体检跳转到「未绑定任务包」的小游戏题就会踩到。已改为数组兜底。
- **问卷大厅卡片高低不齐**：有封面/无封面混排时，卡片底部按钮不在同一水平线。
  已改为统一媒体区 + `mt-auto` 页脚 + `auto-rows-fr`。
- **封面失效留空**：`onError` 只隐藏 `<img>`，媒体区变成空色块；现在媒体区本身
  有渐变/点阵兜底。
- **搜索替换整批替换不可用**：大小写不敏感且只改大小写时，部分命中替换后等于
  原文，原实现会整批禁用；现在只提交真正会变化的命中。
