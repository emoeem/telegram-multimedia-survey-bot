## 一、你问的「右边那块」是什么

那是**结果设计器**（给问卷配「评分维度 → 分数 → 结果区间」的计分规则）+
它自带的「实时结果预览」调试卡。乱的三根因全部查实并修复（commit `6257830`）：

1. 360px 右栏塞进了为整页宽设计的双列面板，内层 320px 硬下限把配置列压成
   0 宽——「评分维度 题目→分数→结果」**逐字竖排**成假步骤条；
2. 你没配过评分维度它也全展开（基础/专业模式零门控）——一坨空态卡片；
3. 手机端（≤999px）右栏整体 display:none，设置在手机上**没有入口**
   （你 390 截图里盖住页面的内容来自旧壳路径/手机桌面模式视口）。

修后形态：右栏默认只显示设置表单 + 一张「📊 结果设计器 ›」折叠入口卡；
点开单列堆叠（容器查询）；基础模式显示「专业模式可用」引导；手机端选中
「问卷设置」时表单直接在中栏展开。

## 二、后台信息架构工作区化（你的提案，commit `00a3c77`）

> 「为什么最左侧一定要有那么多面板……点问卷这个分类整个界面就不一样」

按此重构为两层导航（路由不变）：

- **全局图标轨（56px 常驻）**：总览 + 四个工作区（问卷/内容/社区/系统）
  各一个图标；
- **工作区子导航**：进入工作区后主区域顶部出现该工作区的横向 tab
  （问卷 = 列表|分类|导入|答卷动态|报告，报告从「内容」组挪入——它是答卷
  产出的归档），其余工作区全部隐去；
- **创作沉浸态**：编辑器/场景编辑器隐藏图标轨与子导航，整宽渲染；
- creator 角色、授权中心开关的过滤逻辑平移；旧侧栏的折叠组/紧凑轨/
  「更多」面板机制退役（56px 轨没有装不下的高度问题）。

走查 5/5：总览图标轨、问卷 tab×5、编辑器沉浸（sidebar display:none）、
内容 tab×6、手机 390 无溢出。
