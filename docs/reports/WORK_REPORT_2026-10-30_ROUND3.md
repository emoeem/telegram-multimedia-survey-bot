## 一、B. 答题页沉浸式布局重设计（先做）

### 1.1 根因诊断（B1，先写清楚再动手）

**「线上 1920+ 宽度场景图仍居中窄条」不是部署落后。** 实测证据：

- 抓取线上 `https://emoe.eu.cc/assets/pwa-IePm0iC6.css`：已包含 2026-10-29 舞台版式
  （`.survey-stage{position:fixed...}` + `.stage-frame-box{width:min(100cqw,...)}`），
  即线上 = 最新代码；
- 真正根因是 `.stage-frame-box` 的 **contain-fit 结构性留黑**：
  1920×1080 下舞台区约 1920×900，16:10 场景框被压到 **1294×808（50.4% 视口面积）**，
  两侧各 313px 纯黑；
- 移动端更糟：display=auto + 宽度 <1024 走 reading 版式，390 竖屏场景缩在
  `max-w-xl` 卡片里 **308×192（18% 视口面积）**。

## 二、A. 统一节点编辑器

### 2.1 选型（A0）

**@xyflow/react 12.12.0（React Flow）**。依据：58.6 kB gzip（bundlephobia）
vs 自研 1000–1500 行 + 5–10 人天；触屏双指缩放、键盘可达性、视口裁剪白送；
React 19 官方支持。**实测增量：admin 总 gzip 676.6 KB → 736.9 KB = +58.8 KB，
全部落在编辑器懒加载 chunk，答题页零增量。**

### 2.2 架构（A1）

**画布是视图，问卷 JSON 是唯一存储。** 节点图由 survey JSON 派生
（`admin/src/editor/node-graph/to-graph.ts`），写路径全部映射回既有命令
（`commands.ts` 纯函数 → `patchQuestionLocal` + `queueQuestionPatch`），
不发明新存储格式。因此：

- 存量问卷天然兼容（不新增字段、不改 schema）；
- 「round-trip 无损」在结构上成立：无损 = graph 完整保真表示 survey
  （单测 `tests/unit/editor/node-graph.test.ts` 钉住）。

节点语义与现有题型一一对应：剧情文本幕=note、场景幕=scene、
quest 道具=game（meta 读任务包名）、分页=pages 派生、结束幕=提交/认证卡挂钩
（合成节点）；分支 = condition（选项跳转/flag/答案规则/skipTo），
复用 `buildCanvasEdges` 同一真相源。

### 2.4 简单性（A2）与移动端（A3）决策

- **纯问卷用户不该感到画布的存在**：画布形态默认「列表」（现有卡片流，
  零行为变化）；「节点图」是显式 opt-in（`?canvas=graph` 或顶栏切换）。
  纯线性问卷在节点图里也是一条直线链（无分支时零条件边）。
- **拖入自动接链尾**：既有 addQuestion 语义（追加末尾），列表/节点图一致；
- **A3 选方案 a（移动端列表式编辑）**：节点图需要确定高度的画布视口，
  而编辑器三栏在 <1000px（既有断点）折叠为纵向流，结构上放不下；
  窄屏节点图按钮禁用 + 「节点图需要桌面端宽度」说明，用户偏好保留
  localStorage、回桌面宽度即恢复。列表承担全部编辑（拖入接链尾/排序/
  点卡片编辑）。390px 实测截图：`_review/node-editor/editor-fallback-390.png`
  （按钮禁用 PASS、提示文案 PASS、无横向溢出）。

## 三、待确认决策（无人值守期间的取舍）

1. **场景题全宽度上舞台是行为变化**：display=auto 的存量问卷在手机竖屏
   会从阅读窄卡变为全屏舞台（这正是 B 任务主诉的修复）。作者若要旧行为，
   目前无逃生门——建议下轮给 `settings_json.display` 增加 `"classic"` 值
   （成本：display.ts 枚举 + layout.ts 一行 + 编辑器显示模式选择器）。
2. **编辑器画布形态默认 list**（铁律「验收前不切默认」）：验收通过后是否
   把默认切到 graph、或对「含 note/scene/game 的问卷」默认 graph，待定。
3. **连线语义 = 默认跳转**（skipToQuestionId）：选项级分支（选 A 跳 X）
   仍在属性面板/逻辑面板配置。理由：一条连线一个语义，删除精确可逆；
   画布上画选项级多边会爆炸。是否要在画布上支持选项级连线，待定。
4. **分支删除主路径 = 节点角标菜单**：同列布局下分支边会被中间节点遮挡
   （interaction path 不可达，走查实测），右键保留为无遮挡布局的补充。
   若后续要做边自动绕行（自定义 edge），另行评估。
5. **视觉门禁 110 个存量失败**（本机字体渲染漂移，干净树等价复现）：
   未盲目重建基线。建议在基线截图同环境重建，并把截图测试按环境分桶。
6. **编辑器惰性大图体验**：58+ 题的链初始取景锚定图首（0.5×），
   是否要「横向时间轴」形态（galgame 链左→右），待定。
