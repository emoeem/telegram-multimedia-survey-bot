## 一、面向参与者（可以直接转发到社群）

### 🔞 内容分级与年龄确认

- 平台内容现在分「全年龄」与「18+」两档；未确认年龄时，目录、广场、
  展示区与抽卡池都不会出现 18+ 内容。
- 目录页顶部会提示「还有 N 份 18+ 问卷未显示」，点一下确认即全部可见；
  确认状态按你的身份记住，之后不用重复确认。

### 🃏 结局分享卡（新）

- 每份完成的答卷都能生成一张**结局分享卡**：公开的只有结局名和卷名，
  **任何答案内容都不会出现在卡片上**。
- 分享链接永久有效、可随时撤销；18+ 问卷只生成含蓄的 teaser 卡（不含
  内容细节），链接在任何地方预览都是安全的。

### 🗂️ 单卷结局图鉴（新）

- 多结局问卷完成时会解锁对应结局，完成页显示「🗺️ 结局图鉴 2/4」。
- 未解锁的结局显示为「？？？结局」——走别的选择，可以把它们全部收集。

### 📖 系列书架与追更（新）

- 「书架」页把连载作品按系列聚合：显示章节数、我的阅读进度、续读入口。
- 关注系列后，作者发布新章节会收到站内通知（绑定了 Telegram 的还会
  收到私信提醒）。

### 🎬 视觉小说模式（新，作者开启后生效）

- 开启 VN 模式的问卷：场景图铺满全屏、剧情文字逐字打出、叙事卡变成
  带说话人名牌的对话框，像在读一部互动小说。
- 进度条按你实际走过的剧情路线计算，分支选择下不再跳变。

### 👤 账号体系升级

- **填写问卷现在需要注册或登录**（邮箱即可，一分钟完成）：进度、结局收集、
  追更与金币从此跟着账号走，换设备不丢。
- 用 Telegram 打开则自动使用 TG 身份，无需注册。
- 「我的」页身份卡会明确显示你是邮箱账号、TG 身份还是未注册访客。
- 登录后，此前在同一个浏览器里匿名填过的历史答卷会自动并入账号
  （打开「我的」页即触发）。

### 💬 树洞支持网页直接发言

- 不再要求必须通过 Telegram：注册邮箱账号后即可在网页端发帖、评论、
  传配图。

## 二、面向创作者（编辑器）

### 🌿 剧情引擎：好感度 / Flag 系统（新）

- **选项命中 Flag**：给任意单选选项绑定「flag 名 + 分值」，答题者选它
  就累计（负分可经 JSON 导入设置）。
- **Flag 门槛跳转**：当某 flag ≥ 门槛时，直接把读者跳到目标节点——用来
  做好感路线、真结局锁定。
- 与既有跳转机制（选项跳转、历史答案跳转）完全兼容，互不覆盖。
- Flag 由已保存的答案确定性重放：中途退出再续答，路线不会丢。

### ▶️ 编辑器内试玩（新）

- 实时预览面板新增「试玩」：从任意节点出发，**按与玩家完全一致的跳转
  规则**走一遍剧情，底部显示走过的节点足迹，可回退、可看终局统计。
- 试玩能验证的：选项跳转、历史答案跳转、Flag 门槛跳转。

### 🎨 视觉小说表现层（新）

- 叙事卡（剧情文段）新增「说话人」字段——VN 模式下显示为对话框名牌。
- 主题面板新增「视觉小说模式」开关：打字机文字（尊重系统"减少动效"设置）、
  全屏场景背景、对话框叙事卡。

### 🌹 连载/系列（新）

- 可以把多份问卷组织成**系列**（一部作品 = 多个章节），设置章节顺序。
- 读者端获得书架、续读、追更；发布新章节时自动通知全部关注者。
- 章节的金币解锁沿用既有付费体系，连载作品天然支持逐章解锁。

### 🎁 结局收集奖池（新）

- 结果设计里的多个结局可**一键生成抽卡奖池**（「生成结局奖池」按钮）：
  读者完成答卷后花金币抽取结局卡，池子默认草稿态，价格与上架在后台调。

### 🤝 朋友互测（新）

- 把一份答卷设为「答案钥匙」后，其他人的报告和分享卡会显示默契得分
  （「默契 6/10」）。钥匙答案本身永不下发。

### ♻️ 其他编辑器改进

- 「18+ 内容」分级开关（从 18+ 改回全年龄由管理员操作，防误触）。
- 报告默认样式统一为**经典报告**（作者显式绑定的模板优先）。

## 三、面向运营 / 管理员

### 📋 内容分级管理（管理后台 → 问卷）

- 列表新增「分级」列：点击单卷徽章即可在「全年龄 / 18+」间切换
  （放宽为全年龄需二次确认）。

- **批量标注**：勾选多份问卷，一键「标为 18+ / 标为全年龄」（仅管理员；
  全年龄方向需确认；操作写审计日志）。

### 📨 站内通知系统（新）

- 连载更新通知、后续的用户召回入口都汇入「我的」页通知区块。

### 📊 身份统一带来的数据修正

- 活动数据现在按「人」统计：邮箱用户的答卷、金币、成就、成就解锁、
  解锁记录、抽卡收藏、挑战排行榜全部正确归属到账号（跨身份自动并集）。
- 挑战排行榜「我的」标记按人判定，绑定前的旧记录也算本人。

### 🖼️ 个人画像（Wrapped）

## 五、技术变更摘要

| 迁移 | 内容 |
| --- | --- |
| `0080_content_rating` | 分级列 ×5 表 + `participant_preferences`（年龄确认） |
| `0081_report_shares` | 结局分享卡（DB 随机 token，可撤销） |
| `0082_identity_links` | `participant_hash_links` 映射（写侧归一 / 读侧并集） |
| `0083_series` | 系列表 + 章节归属 |
| `0084_follows_notifications` | 关注 + 站内通知 |
| `0085_profile_shares` | 个人画像快照分享 |
| `0086_ending_unlocks` | 单卷结局解锁记录 |

- 审核链路：注册墙（开卷/作答/提交/上传四入口，401 `registration_required`，
  SPA 弹登录门）；TG 打开的路径不受影响。
- 身份桥：邮箱注册自动创建合成 users 行（id 段 1e12+，与真实 TG 隔离），
  三套身份统一到 `user_{id}` 视角；金币合并走幂等 `merge_in` 交易
  （重复绑定不重复吸收，防刷）。
- 连载召回通知经 SELF binding + HMAC 签名内部端点异步执行（TG push
  失败静默，不拖住发布响应）。
