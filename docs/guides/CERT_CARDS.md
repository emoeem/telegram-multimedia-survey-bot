# 趣味认证卡生成器（`/cert`）

一个纯前端、零构建、零后端依赖的静态页面：所有渲染都在浏览器 Canvas 里完成，**照片与勾选内容不上传服务器**。
入口：`https://<worker 域名>/cert`（Worker 里 `/cert` 302 到 `/cert/`；Telegram 主菜单有「🪪 趣味认证卡」直达按钮）。

## 1. 文件与构建

```
cert/
├── index.html        页面结构（脚本引用带 ?v= 版本号，改完记得手动加一版防缓存）
├── styles.css        界面样式，设计令牌与问卷 SPA 对齐
├── themes.js         内置 8 套中性主题（打工人/猫奴/程序员/咖啡/玩家/健身/美食/熬夜）
├── themes-adult.js   成人向主题包（19 个板块 / 1050 条词 / 9 档等级），**不随页面加载**
├── presets.js        问卷 daisyUI 8 套预设调色板（与问卷主页共用 localStorage.surveyPreset）
├── render.js         26 种版式的 Canvas 渲染（含多图拼贴引擎与证件族）
├── app.js            交互、状态、导出、分享、18+ 门禁
└── vendor/qrcode.js  vendored qrcode-generator 1.4.4（MIT）
```

`pnpm build:admin` 前会跑 `scripts/sync-cert.mjs`，把 `cert/` 原样拷进 `admin/public/cert/`，因此 `pnpm deploy` 自动带上；
Worker 侧 `/cert/*` **只对无扩展名的路径**重写 `index.html`，带扩展名的走静态资源（早期版本把 js/css 也重写成 html，导致整页白屏）。

## 2. 18+ 门禁（只对成人词库生效）

- 成人主题不在 `index.html` 的 `<script>` 里，`app.js` 在用户点「我已满 18 岁，加载词库」之后才动态注入 `themes-adult.js`；
  **未确认前浏览器里没有这份词表**。
- 确认状态存 `localStorage["cert-card-maker:adult-ok"]`，确认后下次直接加载，面板上有「收起成人内容」可以撤销。
- 中性 8 套主题不需要确认，默认入口就是它们。成人主题在主题列表里始终排在最后、脚注标明词库来源。

## 3. 评分模型（两套，按主题切换）

|      | 中性主题                      | 成人词库                                                               |
| ---- | ----------------------------- | ---------------------------------------------------------------------- |
| 强度 | `勾选条数 ÷ 总条数`，0–100%   | `Σ 词条分值 ÷ 60 × 100`，**允许超过 100%**                             |
| 等级 | `ranks` 的 `0–100` 区间，5 档 | 9 档按 `min` 阈值（0/10/25/40/60/85/110/160/250），带 `grade` + `rare` |
| 称号 | 区间里写死的名字              | 按「姓名哈希 % 候选数」从该性别的 3 个称号里稳定取一个                 |
| 判词 | —                             | 每档 3 条评语，按 `(姓名哈希 + 原始分值) % 3` 取                       |
| 徽章 | —                             | 板块徽章：选满该板块**当前性别可见条数的 35%**（至少 4 条）即点亮      |

分值与阈值口径与来源站（seal.jiyu12.com `js/app.js` 的 `scoreOf()`）一致：分母固定 60，所以选得越多百分比越大，
进度条会按 100% 封顶、数字照实显示。

词条对象形如 `{ t: "词条", s: 1|2|3, g: "u"|"f"|"m" }`：`s` 是轻/中/重分值，`g` 是通用/雌性/雄性。
词条编辑器里的字段是 `{id, text, on, g:<组名>, sex, score}`——注意 `g` 已被「所属板块名」占用，性别用 `sex`。

### 性别切换

成人主题带 `genderAware: true`，面板出现 `♀ 雌性 / ♂ 雄性` 开关（默认雌性）：

- 切换后 `groupVisibleTotal` / `tagVisible` 只保留 `sex === "u" || sex === 当前性别` 的词；
- 某个板块在该性别下一条都没有时整块隐藏；
- 组头会显示「N 条异性词」提示被隐藏的数量；
- 强度按切换后的可见词重算，所以同一批勾选换性别是不同分数。

## 4. 标题预设与分享

- 17 个认证标题（`公狗认证 / 贱狗认证 / 骚货认证 / …`），按性别各一套，点一下替换副标题与徽标文字；也可以完全手写。
- 分享链接 v2：`#s=base64url(JSON)`，字段 `{v:2, t, s, r, n, no, vu, ap, mp, g:<性别>, tags:[[text, 组, 是否勾选, 性别, 分值]]}`。
  对方打开链接即可还原同一张卡（勾选、性别、强度、姓名、主题、版式、比例全带上）。二维码默认指向该分享链接。

## 5. 26 种版式与多图

选择器分三组：**证件样式（13）/ 创意版式（13）/ 成人向证件（3，18+ 后出现）**。
比例 1:1 / 4:5 / 3:4 / 9:16 / 长图（1080×2700），任意组合导出 PNG 或复制图片。

### 5.1 证件样式（拟真证件，`group: "doc"`）

照真证件的版式与字段排：防伪底纹（交叉网纹 + 同心环）、微缩文字、金属芯片、全息标、钢印、机读码。
**身份证**、**学生证**、**工牌**、**驾驶证**、**结婚证**、**就诊卡**、**会员卡**、**准考证**、**宠物证**、**荣誉证书**。

- 字段按真证件命名（姓名 / 性别 / 出生 / 住址 / 公民身份号码 …），值全部来自站内数据：
  姓名、编号、主题的发证机构、等级、勾选词条、有效期。
- 仿真但有据可查：18 位号码由编号补齐、末位按 GB 11643 算校验码；出生日期与考场/座位由编号哈希**确定性**派生
  （同一编号每次一样，不是随机）。
- 比例适配：真证件是横的，所以**不把证件拉满画布**。`docStage()` 把证件按真实长宽比居中「摆」在台面上，
  下方接认证项目、等级、百分比、二维码与发证信息；方形比例下台面占比更小，长图则把认证区做成带边框的铭牌。
- 照片位复用多图拼贴；结婚证会把前两张照片左右并排（`photoMode !== "single"` 时）。

### 5.2 创意版式（`group: "fun"`）

资格证（窄高比自动切换为竖版）、环绕词云、混乱词云、印章满屏、宾果表、化验单、小票、狗牌、SSR 卡牌、成分表、通缉令、
**拍立得照片墙**、**印样联片**。

### 5.3 成人向证件（`adult: true`）

**认主契约**（条款区逐条列出勾选词条，落款盖章 + 手印）、**畜籍证**（耳标、档案照遮眼条、检疫栏）、**识别卡**（编号 + 等级 + 可用项目 + 条码）。

和成人向词库同一套门禁：`app.js` 里 `renderStyles()` 直接**不把这几项放进 DOM**，不是 CSS 隐藏；
点「我已满 18 岁」后 `renderStyles()` 重跑才出现。三条防线：

1. 存档里存着成人向版式但没解锁 → `safeStyle()` 回退到第一个非成人向版式，并同时改写 `state.styleId`，
   否则画布回退了、选择器却一个高亮的都没有；
2. 分享链接带着成人向版式 → 同样回退，但姓名/标签照常还原（不因为版式被挡就连内容一起丢）；
3. 「收起成人内容」时若正停在成人向版式，先回退再重绘。

### 多图（一张卡上排多张照片）

照片从"多张里挑一张"改成"多张一起上卡"：

- `photos` 队列里每张带 `on` 标记，点缩略图 = 上卡/下卡，角标显示它在卡上的第几张（1..N）；上限 `PHOTO_MAX = 9`（3×3）。
- 卡片侧：`photoList(m)` 返回所有已上卡且解码完成的图片，交给各版式的照片位。
  - 只有 1 张、或用户把「多图拼贴」切成「只放第一张」时，直接 `cover()` 铺满；
  - 多张时走 `collage()`：`gridFor()` 在 1..4 行列里挑「空格最少 + 单格长宽比最接近照片位」的组合，
    **等大格子**铺满，格子间缝隙露出相纸白（`mat`），不再出现"某一行横跨整幅"的失衡；照片数不是格数整数倍时空格留白。
  - 「照片上压姓名/日期」开关（`photoOverlay`）在照片左下压一层渐变条，照片位太小自动跳过。
- 两个专门为多图做的版式：
  - **拍立得照片墙**：白边相纸 + 微旋转 + 投影，最多 5 张；4~5 张自动分两行，相纸间距按可用宽度缩放，编号与日期不再被下一张遮住；
  - **印样联片**：深色相纸 + `#01..#09` 编号 + 未曝光空格（虚线框 + 破折号），最多 9 张，3 列网格。
- 照片只存 `URL.createObjectURL`，**不落盘也不进分享链接**（刷新即清空），所以多图只影响当前这张卡。
- 缩略图顺序 = 用户选择的顺序：`addFiles()` 立刻把条目压进数组，再异步 `onload`——否则 `Image` 解码顺序会把缩略图打乱。

成人主题在版式里额外挂三处装饰，都由同一个模型对象驱动：

- `rankLabel(m)`：等级称号 + 等级字母（称号里已含等级字母时不重复）；
- `badgeRow(m)`：点亮的板块徽章胶囊，超宽自动从尾部丢、再缩字号；
- `sayLine(m)`：该档的倾向判词。

**版式适配说明**：混乱词云与环绕词云是"满屏词"的卡，任何附加小字都会糊在词上——混乱词云不画徽章与判词，
环绕词云把徽章放到称号上方；成分表在成人主题下只列**你选中的**词（词库一千多条，全列会溢出画布）；
小票把徽章与判词放在表头分隔线下（底部没有垂直空间），并按实际画出的条目数推进光标。
照片位在资格证/化验单/小票等版式里是固定区域，多图会在该区域内拼贴，不会撑破版面。

## 6. 后台内容包

- 管理页：`/admin` → 内容 → **认证卡内容**（`admin/src/routes/CertContentPage.tsx`，路由 `/cert-content`）。
- 接口：`GET/PUT/DELETE /api/admin/cert-content`（PUT/DELETE 仅管理员，写审计日志 `cert_content.save` / `cert_content.reset`）。
- 存储：复用 `system_settings` 表的 `cert_content_pack` 键存 JSON，**没有新增数据库迁移**。
- 生成器启动时 `GET /api/cert-content` 拉包；**拉不到就用代码内置主题**，因此线上不配置也能用。
- 校验上限（`src/http/admin/cert-content.ts`）：主题 ≤ 40 套、每组标签数 ≤ 200、分区 ≤ 24 组、扁平标签 ≤ 4000 条、
  标签 40 字、组名 12 字、等级 ≤ 24 档、`min` 上限 999（成人档位超过 100%）。
- 主题可选字段：`metric{kind:"score",divisor}`、`genderAware`、`adult`、`titles{f,m}`、`sectionTypes{id:{f,m,adj,say}}`、
  `groups[].badge`、`ranks[].grade/rare/f/m/say`。后台编辑器目前只维护中性主题用得到的字段，成人主题是静态文件。

## 7. 重新生成成人词库

```bash
node scripts/import-cert-adult-words.mjs /path/to/words.js   # 产出 cert/themes-adult.js
```

脚本在 `vm` 沙箱里跑一遍来源站 `words.js`，复用源站自己的 `SECTIONS` 解析结果（`<性别><分值> <词条>` 多行文本），
再补出 `RANKS` 的 `max`、拼好 `SECTION_TYPES`，输出 `window.CERT_ADULT_THEMES`。
词库来源与授权：seal.jiyu12.com 的 `js/words.js`，本项目已获作者授权使用；**换词库前请重新确认授权**。

```bash
npx playwright --version                          # 手工冒烟脚本用（临时文件，不入库）
```

  板块徽章点亮、13 种版式 × 5 种比例全部出图无 pageerror；
- 多图验收（Playwright，22 项全过）：一次上传 5 张 → 缩略图顺序与选择顺序一致、默认全上卡、序号 1..5；
  点缩略图上下卡、只留第一张 / 全部上卡、排法切换、照片压姓名开关都会改变画布哈希；
  26 种版式（含成人向 3 种）× 5 种比例共 130 组合全部出图、无 pageerror；拍立得与印样联片在 5 张时与 1 张时画面不同；无 pageerror；
- 拼贴网格回归：n=1..9 各出一张（1 张铺满、2 张 1×2、3 张 1×3、4 张 2×2、5~~6 张 2×3、7~~8 张 2×4、9 张 3×3），
  印样联片 7~9 张自动转 3 行；

- 注册表单测：`tests/unit/cert/render-registry.test.ts` 用假 window 跑一遍 `render.js`，钉住 id 唯一、
  每个版式都有 `render`、分组只有 doc/fun、成人向都打了 `adult` 且都在 doc 组、`findStyle` 回落、五种画幅齐全；
- 18+ 门禁实测：未解锁时成人向按钮**不在 DOM**（不是 CSS 隐藏）；存档或分享链接带着成人向版式会自动回退到
  「身份证」且姓名/标签照常还原；「收起成人内容」时同样先回退再重绘。
- 仓库门禁：`pnpm typecheck`、`pnpm test`、`pnpm build:admin`（会跑 `sync-cert`）。

## 9. 单文件离线版（用户「打不开」时的兜底）

线上 `/cert/` 托管在 Cloudflare。**服务端没有问题**，但少数网络到 Cloudflare 这一跳会被拦，
对用户来说就是「打不开」。为此多产出一条自包含的 HTML：

```
scripts/build-cert-single.mjs   →  cert/cert.html（约 302 KiB）
```

由 `pnpm build:admin` 自动生成（`build:admin` = `build-cert-single` → `sync-cert` → `vite build`），
产物随 `sync-cert` 一起进 `admin/public/cert/`，所以线上也能下载：
`https://emoe.eu.cc/cert/cert.html`。

内联了什么：`styles.css`、`vendor/qrcode.js`、`themes.js`、`presets.js`、`render.js`、`app.js`，
以及成人词库（作为 `<script type="text/plain" id="cert-adult-pack">` 惰性内联，
用户点「18+」后由 `app.js` 转 Blob URL 执行，`file://` 下同样能解锁）。

与线上版的差异（有意）：

- 不请求 `/api/cert-content`，直接用 `themes.js` 内置主题（`fetchServerPack()` 在非 http(s) 下直接返回 null）；
- 注入 `CERT_SHARE_BASE = https://emoe.eu.cc/cert/`，`file://` 下生成的分享链接照样是线上地址；
- 生成时自检：标签层不允许残留任何非 `https?:|data:|#|javascript:` 的 `src`/`href`。

分发方式：把 `cert/cert.html` 当文件发给用户（Telegram / QQ / 网盘），对方双击用浏览器打开即可，
照片依旧只在本机 `object URL` 里，不上传任何服务器。

### 启动看门狗

`index.html` 里有一段 5 秒定时器：`app.js` 的 `boot()` 成功后才给 `<html>` 打
`data-cert-ready="1"`；超时没等到就显示 `#bootFail`，内容包含「可能是网络被拦」与离线版下载按钮。
实测线上置位耗时 **320 ms**，不会误报。
