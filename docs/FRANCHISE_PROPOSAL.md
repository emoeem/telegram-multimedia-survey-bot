## 一、我们是谁

我们运营着一个**基于 Telegram 的多媒体问卷与社区互动平台**，并已建成配套的**人物/作品展示区**。

一句话概括它的形态：

- **普通用户**在 Telegram 里点一下，就能打开一个手机优先的网页问卷，答题、上传图片、生成个人报告；
- **管理者**拥有一个完整的网页后台，创建问卷、管理答卷、查看统计、发放报告，全部可视化操作；
- **答卷和报告**自动归档、自动生成 PDF、自动推送到指定频道；
- **展示区**以「一屏一人」的沉浸式方式展示创作者、成员或作品，每张人物页都可以单独分享。

这不是一个 PPT 里的构想，而是**已经在线上稳定运行的产品**：全栈部署在 Cloudflare 全球边缘网络上，无需自购服务器，全球访问低延迟；核心链路（答题、报告、归档、后台管理）均经过真实用户和自动化测试验证。

### 技术底座（给你信心，不需要你懂技术）

| 组成 | 说明 |
| --- | --- |
| 部署架构 | Cloudflare Workers 全球边缘计算，无单点服务器，免运维 |
| 数据 | 独立数据库（D1），结构化存储答卷、用户、媒体 |
| 媒体 | 图片等媒体文件独立存储，访问权限逐条控制 |
| 异步任务 | 队列驱动，PDF 生成、报告投递失败自动重试 |
| 质量保障 | 数百个自动化单元测试 + 真实浏览器回归测试 |

## 二、为什么做这件事：我们看到的痛点

如果你在运营一个 Telegram 群组、频道、社团或创作者社区，这些场景你一定熟悉：

1. **收集信息靠接龙和截图**——报名、投票、统计全靠人工复制粘贴，人一多就乱、就漏。
2. **问卷工具与社群割裂**——用第三方表单，用户要跳出 Telegram，链接散落在聊天记录里，回收率低。
3. **答卷数据没有归宿**——收上来的信息躺在别人的服务器里，导出困难，更别说自动生成报告。
4. **成员和作品没有「门面」**——社群里有优秀的创作者、有拿得出手的作品，却只能靠置顶消息和相册展示，杂乱且不体面。
5. **想自建一套系统，成本高得离谱**——要么雇开发团队（数万到数十万），要么用现成开源方案自己折腾服务器、安全、备份、升级。

我们的平台就是为了解决这些问题而生的。而**加盟**，是让你以极低的门槛，直接获得这套已经打磨成熟的系统。

## 三、平台能做什么：功能全景

### 3.1 多媒体问卷系统

- **全题型支持**：单选、多选、填空、图片上传等，题面和选项都可以带图片；
- **手机优先的填写体验**：进度条、分页、跳题逻辑、断点续填（填一半退出、回来接着填）；
- **访问控制**：支持问卷密码 / 访问码，私密问卷不外泄；
- **防丢设计**：答卷绑定提交时的问卷版本，问卷后续修改不影响历史数据。

### 3.2 报告系统

- 每份答卷自动生成**网页版个人报告**，手机上直接阅读，样式精美、支持多模板；
- 每份答卷自动生成 **PDF 归档**，推送到你指定的 Telegram 频道，带标签可检索；
- 投递失败自动重试，后台可随时查看状态、手动重发。

### 3.3 完整的网页管理后台

你（作为加盟方管理员）拥有一个功能完整的控制台：

- 仪表盘：答卷总数、今日数据、交付状态一目了然；
- 问卷编辑器：可视化拖拽排版题目、选项，实时预览，版本管理与恢复；
- 答卷管理：筛选、详情、媒体预览、导出；
- 用户目录：查找成员、打标签、一键跳转私聊；
- 审计日志：所有管理操作留痕，多人管理也不怕出乱子。

### 3.4 Telegram Bot 深度集成

- 用户在你的 Bot 里 `/start` 即可进入，无需额外 App；
- 答卷完成自动通知、报告链接直达；
- Bot 即入口、即通知渠道、即归档通道——用户全程不离开 Telegram 生态。

### 3.5 展示区（详见下一章）

一个让社群「有面子」的沉浸式展示空间。

## 四、展示区：你的成员/作品该有一个体面的舞台

展示区是整个平台最具视觉冲击力的部分，也是社群对外宣传的天然名片。

### 它长什么样

- **全屏沉浸式舞台**，一位创作者/一个人物占一整屏；
- 左右滑动即可切换人物，背景、主题色、氛围随人物联动过渡，流畅跟手；
- 点击人物立绘，从底部滑出资料面板：简介、标签、社交链接、精选作品、关联问卷；
- **每个人物都有独立分享链接**，可以直接发到群里、频道里、朋友圈里。

### 它能用来做什么

- **社群成员风采墙**：把活跃成员、优秀创作者做成一页页可分享的电子名片；
- **作品集展示**：画作、文章、视频、项目、GitHub、社交账号，一个面板全部收纳；
- **活动宣传位**：重要人物/作品可设为「精选」，优先轮播展示；
- **引流入口**：每个展示页可关联问卷（如「查看 TA 的作品集问卷」），展示与互动打通。

### 对加盟方的意义

> 一个链接发出去，别人对你的社群的第一印象不再是一串聊天记录，而是一个精致、专业、有设计感的展示空间。

## 五、加盟模式：独立部署，一站交付

我们的加盟模式核心是：**你拥有自己的一套独立平台实例，而不是在我们平台上租一个角落。**

### 5.1 你将拥有什么

| 组件 | 归属 |
| --- | --- |
| 你自己的 Telegram Bot | ✅ 完全属于你，用你的 BotFather Token |
| 独立的数据库 | ✅ 你的答卷、用户、媒体物理隔离，只有你能看 |
| 独立的媒体存储 | ✅ 图片等文件独立存放 |
| 独立的展示区 | ✅ 展示你自己的成员和作品 |
| 完整网页管理后台 | ✅ 你和你的管理员团队专用 |
| 全球边缘网络部署 | ✅ 与我们主站同级的访问速度和稳定性 |

### 5.2 与「租用平台」的区别

```
传统方式：  你的数据 ──→ 别人的平台 ──→ 你只是众多租户之一
加盟方式：  我们交付 ──→ 你自己的独立平台 ──→ 数据、Bot、展示区都是你的
```

- **数据主权在你**：所有答卷、用户信息存在你的独立数据库里，与我们、与其他加盟方完全隔离；
- **品牌是你的**：用户看到的是你的 Bot、你的名字，不是我们的；
- **不依赖我们的服务器存活**：每个实例独立运行，互不影响。

### 5.3 我们持续提供什么

加盟不是一次性买断，而是持续的合作：

1. **免费持续升级**——我们开发的新功能（新题型、新报告模板、展示区新能力）会通过一键批量升级推送到你的实例，升级不丢数据、不换 Bot、用户无感知；
2. **版本管理**——每个版本经过登记和验证后才推送，出问题可回滚；
3. **技术兜底**——部署、迁移、疑难问题由我们处理，你不需要任何服务器运维知识。

### 5.4 加盟门槛

对加盟方的要求很简单：

- 有自己的 Telegram 账号（用于创建你的 Bot 和管理后台）；
- 有一个正在运营或准备运营的社群/频道/团体；
- 认同共建共享的合作理念。

> **关于费用**：现阶段我们以共同做大平台为第一目标，具体合作条款（包括费用与权益）在双方沟通后以协议形式确定，本报告书不作单方面承诺。

## 六、不同类型的你，能怎么用

### 6.1 如果你是社群/频道主

- 报名、内测招募、成员信息收集：发一个链接，数据自动回收、自动归档；
- 成员调研与投票：跳题逻辑 + 断点续填，长问卷也不怕流失；
- 频道内容互动：问卷结果自动生成报告，成为频道的内容素材；
- 展示区 = 频道的「官方主页」，对外推广时一个链接说明一切。

### 6.2 如果你是创作者/画师等内容创作者

- 拥有一个精致的**个人展示页**：立绘/头像、简介、标签、社交链接、精选作品，独立链接随处分发；
- 用问卷做约稿表单、设定收集、粉丝互动；
- 答卷自动生成报告，粉丝问卷结果可以直接分享（「我的粉丝画像报告」）。

### 6.3 如果你是社团/组织

- 招新报名、活动签到、成员信息库一站解决；
- 管理后台多人协作，操作全留痕；
- 展示区做「社团成员风采」「优秀作品年鉴」；
- 数据导出方便对接你现有的管理流程。

### 6.4 如果你想运营自己的平台

- 你获得的是**一整套经过验证的产品**，而不是从零开始的代码；
- 无需开发团队、无需服务器运维，专注做运营和增长即可；
- 升级由我们统一推送，你永远用的是最新版本；
- 你的用户、你的数据、你的品牌，全部自主掌控。

## 七、为什么对双方都有好处

这是我们最想讲清楚的一章。**加盟不是单方面的输送，而是一个共同增长的飞轮。**

### 7.1 对你（加盟方）

1. **零开发成本获得成品系统**——省下的是数十万级的开发投入和长期的运维成本；
2. **社群体验跃升**——从「接龙+截图」时代直接进入「专业平台」时代，成员留存和活跃度提升；
3. **持续免费升级**——平台所有人在共同养这套系统，你享受的迭代速度远超自己养开发团队；
4. **规模越大、单位成本越低**——功能由所有加盟方共享摊薄，你永远用得起最新能力。

### 7.2 对我们（平台方）

1. 用户基数扩大，平台得以持续投入研发；
2. 不同类型的加盟方带来不同的使用场景，帮助我们把产品打磨得更全面；
3. 展示区和生态的繁荣，让平台本身更有价值。

### 7.3 飞轮效应：人数多起来之后

```
更多加盟方加入
   → 更多用户在平台上答题、互动、观展
   → 更多真实使用数据和场景反馈
   → 平台迭代更快、功能更强、模板更多
   → 每个加盟方的社群体验更好、更省心
   → 吸引更多加盟方加入（循环加速）
```

具体到将来，随着整体规模扩大，可以逐步探索：

- **联合活动**：跨社群的联动问卷、联合展示、跨社区活动，单一社群做不了的事大家一起做；
- **展示区互通/推荐位**：各加盟方展示区之间的互推与精选联展，把各家的流量汇成合力；
- **共享模板生态**：问卷模板、报告模板、展示主题在加盟方之间流通，一人创造、大家受益；
- **更大的议价与整合能力**：用户规模上来了，无论是接入更多第三方能力还是组织大型活动，都有底气。

> 我们的理念很朴素：**前期不设盈利门槛，先把盘子做大；平台的价值由所有参与者共同创造，也理应由所有参与者共享。**

## 八、安全与保障

安全问题我们按最高标准设计，这也是「独立部署」模式的最大优势：

| 维度 | 保障措施 |
| --- | --- |
| **数据隔离** | 每个加盟方独立数据库、独立媒体存储，物理隔离，平台方和其他加盟方无法看到你的数据 |
| **密钥安全** | Bot Token、访问密钥等全部加密存储在 Cloudflare Secrets 中，不进代码、不进 Git |
| **管理权限** | 后台仅限你指定的管理员 ID 访问；登录链接 5 分钟有效，会话签名校验 |
| **答卷安全** | 支持问卷密码；答卷人身份经 Telegram 签名数据或平台令牌认证 |
| **媒体权限** | 图片仅授权范围可访问，下架即失效 |
| **操作留痕** | 所有管理操作写入审计日志，可追溯 |
| **授权保护** | 加盟实例无法将平台能力二次转授给第三方，保护整个加盟体系的健康发展 |

## 十、常见问题（FAQ）

**Q1：我完全不懂技术，能加盟吗？**
能。部署、升级、疑难问题全部由我们处理，你需要做的只是在 Telegram 里点几个按钮。日常运营（创建问卷、管理答卷、编辑展示区）全部是网页后台的可视化操作。

**Q2：我的数据安全吗？你们能看到吗？**
每个加盟方是独立的数据库和存储，物理隔离。我们技术上无法、商业上也承诺不触碰你的数据。

**Q3：升级会不会把我的数据弄丢？**
不会。升级只替换代码并做增量数据库迁移，答卷、用户、媒体全部保留，用户完全无感知。升级前有版本登记与验证机制。

**Q4：如果以后不合作了，我的数据怎么办？**
数据在你的独立数据库中，可以导出。这一点会在合作协议中明确。

**Q5：用户需要下载什么 App 吗？**
不需要。用户全程在 Telegram 和手机浏览器中完成所有操作。

**Q6：展示区可以放多少人/作品？**
没有硬性上限。展示区为手机端滑动浏览做了专门优化（按需加载背景，只渲染当前页附近内容），人数多也不卡顿。

**Q7：加盟费用怎么收？**
现阶段以共同做大平台为第一目标，具体条款面谈后以协议为准。可以明确的是：门槛会设置在「不让认真做事的人望而却步」的水平。
