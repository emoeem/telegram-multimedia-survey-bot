# 响应式行为规则（RESPONSIVE_RULES）

> 设备矩阵：1440×900 / 1280×800 / 1024×768 / 768×1024 / 1024×768(横) / 390×844 / 360×800 / 390×764(TG) / 844×390。
> 断点：mobile <640 · tablet 640–999 · desktop ≥1000（用户端）/ ≥1024（后台）· wide ≥1280。
> **M6 决策：用户端导航形态切换点以现有产品的 1000px 为准**——`BottomNav` 的 JS `matchMedia("(min-width:1000px)")` 与 Tailwind `lg`（`--breakpoint-lg: 62.5rem`，`admin/src/index.css:51`）以及 `PageHeader` 的 `lg:top-14`、`body:has(nav[aria-label="主导航"])` 56px 顶部偏移构成四方契约，迁移到原型的 900px 需重生成全部基线快照且收益有限。原型文档中的 900px 表述仅指原型自身实现；产品实施一律用 1000px。平板竖屏 768 宽 < 1000 → 底部导航，符合预期。

## 全局铁律

1. **触控目标 ≥44×44 CSS px**（`@media (pointer:coarse)` 提升按钮高度）；hover 永远不是唯一交互。
2. **安全区**：底部导航 `padding-bottom: env(safe-area-inset-bottom)`；Bottom Sheet、Toast、原型面板同理；TG WebView 用 `viewport-fit=cover` + `min-h-dvh`。
3. **无横向溢出**：任意视口 `document.documentElement.scrollWidth <= innerWidth + 1`（CI 断言）；长内容走容器内滚动（`.table-scroll`、`.chip-row`），绝不撑破页面。
4. **动效尊重 `prefers-reduced-motion`**：shimmer/loading/transition 全部静止。
5. **键盘可见焦点**：金色 `:focus-visible` 外圈；弹层 Escape 关闭 + 焦点归还。
6. TG WebView：宿主返回栏不与页面导航叠加（frame=tg 时隐藏 topnav/bottomnav）；软键盘弹起时 CTA 不被遮挡（内容区滚动，无 fixed CTA 压输入框）。

## 分页面规则

### Dashboard（后台）

| 视口     | 行为                                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------------------------- |
| ≥1024    | 60px 图标轨常驻；功能地图 2×2；KPI 5 列（≤1199 转 3 列）；队列表格全列                                              |
| 640–1023 | 图标轨隐藏 → 顶栏汉堡开左抽屉；地图 2×2 收窄；KPI 3 列                                                              |
| <640     | 全部单列；KPI 2 列；表格自动转字段卡（`td[data-label]`）；批量操作浮出为底部操作栏（选中>0 才出现，不遮挡队列尾部） |

### Games 大厅（用户端）

| 视口     | 行为                                                                             |
| -------- | -------------------------------------------------------------------------------- |
| ≥1024    | 三栏：分类(240) + 列表(auto) + 详情(320, sticky)；开始/我的记录/排行榜为分段控件 |
| 640–1023 | 单列：分类横向 chips；详情面板降至列表下方                                       |
| <640     | 底部导航常驻；游戏卡单列；点卡弹 Bottom Sheet（CTA 在拇指区）；试炼设置卡随流    |

### Room 房间（用户端）

| 视口                 | 行为                                                                                  |
| -------------------- | ------------------------------------------------------------------------------------- |
| ≥1024                | 双区：左=规则+玩法选择，右=创建(主) + 加入(次)；CTA 金色主按钮，加入为次级样式        |
| <640 竖屏            | 单列；创建/加入为分段 Tab（默认创建）；玩法卡大命中；输入错误即时内联反馈；Enter 提交 |
| 手机横屏 (≤520px 高) | 强制双列紧凑栅格、隐藏底部导航与 lead 文案，棋盘/表单同屏                             |
| TG WebView           | 宿主返回栏 + 安全区示意；短视口直接可用                                               |

### Profile 个人中心（用户端）

| 视口  | 行为                                                              |
| ----- | ----------------------------------------------------------------- |
| ≥1024 | 12 列栅格：身份(5) + 金币(7) 并排；内容/互动两组各 6 列；偏好通栏 |
| <1024 | 单列纵向：身份 → 金币 → 互动 → 内容 → 偏好（资产靠前）            |
