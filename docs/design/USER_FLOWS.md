# 核心用户流程（USER_FLOWS）

> 原型可操作流程（全部 Mock，不触达真实后端）。对应计划 §7 十项交互要求；Playwright 断言见 `prototype-lab/tests/proto.spec.mjs`。

## F1 实验室控制流

1. 打开 `http://127.0.0.1:4174/`（`node prototype-lab/server.cjs`）。
2. 切换 页面/视口/主题/方向 → iframe 即时换载（设备缩放自适应）；「↗ 新窗口打开」直开页面 URL；选择持久化（localStorage）+ URL 可深链（`?page=&vp=&theme=&orient=`）。

## F2 后台总览工作流

| 步骤 | 动作                                                           | 系统响应                                                                       |
| ---- | -------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 1    | 打开 Dashboard                                                 | 功能地图（4 工作区卡）+ KPI + 报告队列                                         |
| 2    | 点击工作区卡「问卷」                                           | 右侧抽屉列出 1.1–1.5 模块 → 「进入对应页面」跳占位页（后续批次实现真页）       |

| 5    | 点击队列行                                                     | 报告详情抽屉（渠道/状态/时间/答卷 ID + 下载/重投）                             |
| 6    | 按 Escape                                                      | 关闭最上层抽屉，焦点归还触发元素                                               |
| 7    | 勾选多行                                                       | 「已选 n 项」+ 批量重试/下载；移动端浮出底部操作栏                             |
| 8    | 切状态 `?state=loading/empty/error/partial/noperm/queue-error` | 骨架屏 / 零数据 / 错误重试 / 部分失败横幅+KPI 置「—」/ 无权限锁 / 队列异常横幅 |

| 步骤 | 动作                         | 系统响应                                       |
| ---- | ---------------------------- | ---------------------------------------------- |
| 1    | 大厅默认五子棋选中           | 右栏详情：规则、人数/时限、开局设置            |
| 2    | 点「象棋」卡                 | 详情面板切换；卡片描金                         |

## F4 创建房间流（Room）

1. 选择玩法 → 标题/规则/CTA/设置同步（狼人杀/飞行棋出现人数选择）。
2. 点「创建五子棋房间」→ 按钮「正在创建…」（900ms）→ **成功态（明确标注 Mock）**：房间码 GOM-XXXXX。
3. 「复制房间码」→「已复制 ✓」2 秒后复原；「复制邀请链接」同理（链接含 `?room=`）。
4. 等待大厅：座位「你（房主）+ 空位」→ 2.2s 后演示对手加入 → 「开始对局 →」亮起 → toast（正式版进棋盘）。
5. 「← 返回重新选择玩法」回到创建卡。

## F5 加入房间流（Room，13 态）

| 输入                                            | 结果                                        |
| ----------------------------------------------- | ------------------------------------------- |
| 空                                              | 「请输入房间码」                            |
| `abc!`                                          | 「房间码格式不正确（4–6 位）」              |
| `0000…`                                         | 「房间不存在或已解散」                      |
| `1111…`                                         | 「房间已满员」                              |
| `2222…`                                         | 「对局已结束，无法加入」                    |
| `3333…`                                         | 「网络异常，请重试（Mock）」                |
| 其他合法码（如 `9999`）                         | 校验中(800ms) → 加入成功 → 等待房主开局面板 |
| 粘贴链接 `https://emoemok.top/game?room=778899` | 自动解析码 778899 → 加入成功                |

每次输入即清除错误态；Enter 等价点击「加入」。

## F6 个人中心流

| 步骤 | 动作                          | 系统响应                                                             |
| ---- | ----------------------------- | -------------------------------------------------------------------- |
| 1    | 「去注册 / 登录」             | Modal：登录/注册分段；邮箱校验；发送验证码 30s 倒计时（Mock 不发送） |

## 返回链约定

页面内返回一律走显式链接（room→games「← 返回小游戏」、面包屑、抽屉关闭），不依赖浏览器历史；跨页参数用 URL 传递（`?game=chess`、`?from=dashboard&ws=问卷`），保证刷新/直链可达。
