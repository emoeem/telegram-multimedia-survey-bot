## 一、答题页沉浸式重设计（B）

**根因先立住**：「1920+ 场景图居中窄条」不是部署落后——线上 CSS 已是 10-29
舞台版式；根因是 contain-fit 结构性留黑（1920×1080 下 16:10 场景只占
50.4% 视口面积，两侧各 313px 死黑）+ 手机竖屏走阅读窄卡只剩 18%。

- 场景题（scene）全宽度上舞台（含手机竖屏；landscape 模式保留竖屏提示转屏）；
- contain-fit 留白用同一张场景图 blur(22px) 压暗铺满——比例框不动，
  热点坐标语义不变；
- 头部信息条浮层化默认完全让位：把手按钮 / 指针贴边 ≤8px 唤出，
  3.5s 无操作收回，Escape 收起，键盘经把手进入（焦点管理走查验证）；
- 底栏变居中玻璃胶囊；最后一题带「公开发布」区块时保持静态（details
  需要文档流）；题面沉入信息条；
- 修 `main{padding:14px!important}` 窄屏全局规则误伤舞台。

**实测提升（可视面积，before→after）**：桌面 1920 50%→90%、1440 49%→100%、
手机 390 竖屏 18%→29%、844 横屏 43%→74%、iPad 768 竖屏 18%→47%；
微信/QQ/TG WebView 同步提升；全平台零横向溢出，键盘用例布局完好。
截图矩阵存 `_review/immersive-2026-10-30/`（14 平台 × before/after）。

## 二、统一节点编辑器（A，opt-in）

**架构**：画布是视图、问卷 JSON 是唯一存储——节点图由存量 JSON 派生
（剧情文本幕=note、场景幕=scene、quest 道具=game、分页/结束幕为合成节点，
分支=condition），写路径全部映射回既有命令（`patchQuestionLocal` +
`queueQuestionPatch`），不新增字段、不改 schema → 存量问卷天然兼容，
「round-trip 无损 = graph 完整保真表示 survey」由 11 例单测 + 三份真实
问卷回放钉住（93 题纯线性 / 58 题 9 分支生产快照 / 28 题含上传）。

- 画布形态：编辑器顶栏「列表 / 节点图」切换，`?canvas=graph` 直达，
  localStorage 记忆，**默认列表**（纯问卷用户零感知）；
- 节点图能力：连线=默认跳转补丁、分支角标可点菜单（列出/移除单条跳转）、
  拖端口到空白=弹题型选择建新题并接跳转（tempId 经保存管线重映射）、
  拓扑分层布局、大问卷取景钳制 0.5×锚定图首；
- 移动端（A3）：节点图需要确定高度视口，窄屏（<1000px 既有断点）按钮
  禁用 + 说明，列表承担全部编辑——390 实测无横向溢出。
