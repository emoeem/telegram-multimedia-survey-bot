## 一、quest 扩展包生态（本轮主线）

上一轮落地了 quest 扩展包格式与 ZIP 导入；本轮把它推到「真实可玩」：

- **两个新示例包**：悬疑向《午夜站台》（分支钥匙「检票员名牌」解锁隐藏真结局，
  4 结局 + asset 封面图）与温馨向《旧宅寻猫》（钥匙在井房取得、开玄关阁楼门，
  collectible 也能当门控道具）。连同既有示例共 3 个，每个都有引擎剧本级回归
  测试钉住规范假设（多结局分支、跨场景回溯、回路重入不重复计分）。
- **浏览器端到端通关**：在本地真实栈（Worker + D1 + 服务端权威计分）里把两个
  包从问卷 game 题开局玩到结局并提交，得分、道具、结局完全符合剧本预期。
- **顺链路修复的三个断点**：
  1. 编辑器「绑定任务包」写入的 `settings.game` 被服务端白名单静默丢弃——
     扩展包根本绑不进问卷。现已放行并复用读取端同一把校验尺。
  2. 问卷内小游戏宿主请求不带身份头，注册墙下全部 401。
  3. 媒体可见性校验第六路 UNION 触发 D1 的 compound SELECT 上限（=5），
     扩展包插画线上必然 500。已拆为独立语句，并新增「每条语句 ≤4 个 UNION」
     的防回退守卫。

## 二、问卷界面（VN 版式与底栏）

- VN 对话页重设计：底部锚定的玻璃质感对话框（名牌 / 章节 / 唯一推进按钮 /
  返回键），打字机逐字动画期间视为「有操作」。
- 底部操作条自动隐匿三路裁决：向下滚动收起、向上或接近底部浮出、VN 页 4 秒
  无操作收起；软键盘让位语义保留。
- 声音开关从悬浮按钮收进顶栏图标组——此前它会压住 VN 对话框正文，改挂左上
  的旧补丁也仍会盖住节点图，这次是彻底的（有几何无交叠的防回退断言）。
- 场景媒体可见性判定修正（`src/survey/media.ts` + layout 单测）。

## 三、认证卡盖章动画

认证通过的瞬间，印章以 2.4 倍大小自上方落下、轻微回弹后定格淡出，画布同步
一次 0.985 的「受压」。全部只动 transform/opacity，不触发重排、不新增依赖。

## 四、视觉基线进 CI

上一轮人工截的 40 张对比图是一次性的；本轮把最容易回退的四类页面固化进
`pnpm test:visual:gate`（CI visual job）：场景题 1440×900 / 390×844 / 844×390、
VN 对话页（含静音键不压对话框的断言）、认证卡盖章（冻结动画终态，绕开

验证过与既有 211 张基线逐像素对齐。同时修复界面改版后过时的 4 个旧用例。
