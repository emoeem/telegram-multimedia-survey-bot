## 一、问卷大厅（`/s`）

- **Hero**：`SURVEY HALL · 问卷大厅` 小标 + 「每个回答，都值得被听见。」大标题
  - 副文案 + 「开始探索 / 做一张认证卡」双 CTA + 份数/分类/回答数三项统计。
- **右侧纸张插画**：两层旋转纸卡、勾选项、光斑与印章全部由 CSS 绘制，不新增
  图片资源；颜色只走 survey token，暗金 / 暗色 / 明亮三套预设自动适配。
- **工具条**：搜索框（带图标）+ 最新/热门分段控件 + 分类 chips（保留深链）。
- **等高卡片**：统一 128px 媒体区（有封面用封面，无封面用分类图标 + 渐变点阵），
  标题/描述各两行截断，题数·预计时长·回答数一行，页脚用 `mt-auto` 压到底，
  一排卡的「开始填写」不再高低不齐。
- **状态表达**：18+、需密码、金币价格、已填过、已截止、匿名填写都在卡片上有
  明确位置；已填过的 CTA 变为「再答一次」。
- **认证卡入口**：hero 主 CTA + 列表底部的轻量延伸条，两处都可直达 `/cert/`。
- **保留**：暗金默认主题（用户选择）、18+ 年龄门、社区/投稿链接、权威分类计数。

## 二、编辑器

### 问卷体检

新增顶栏「体检」按钮（带错误/警告计数徽章）。规则：

- 跳转目标不存在（error）
- 跳转目标不在当前题之后（warning，引擎会忽略）
- 单选题/多选题没有选项、选项文案为空或重复
- 矩阵题没有列、小游戏题未绑定任务包
- `answerRules` / `flagRules` 引用了不存在的题
- `flagJumps` 消费了没有 `flagRules` 产出的 flag
- 重复题面、叙述节点被设为必答（提示）

点击任意结果：选中对应题目并关闭面板。体检只读，不自动改数据。

### 搜索与替换

`Ctrl+F` 或顶栏搜索按钮打开。范围：题面 / 描述 / 选项标签；支持区分大小写；
结果显示命中片段与替换后文案，点击可定位。替换全部走一条撤销快照 + 按题合并
的 PATCH，整批可一次 `Ctrl+Z` 回退。

### 从当前题预览

题目快捷条新增 ▶ 按钮：用本地未保存快照从该题开始预览，标题栏显示
「从第 N 题开始」。与顶栏「预览」（真实 `/s/:id?preview=1` iframe）分工不变。

### 快捷键

| 快捷键                    | 动作            |
| ------------------------- | --------------- |
| `Ctrl/Cmd+F`              | 搜索与替换      |
| `Ctrl/Cmd+S`              | 保存            |
| `Ctrl/Cmd+D`              | 复制当前题      |
| `Alt+↑ / ↓`               | 上/下切换选中题 |
| `Ctrl+Z`                  | 撤销（既有）    |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 重做（既有）    |

### CSV 结构导出

问卷列表批量导出新增 CSV：一行一道题，列为「问卷 / 问卷ID / 分页 / 题号 /
题型 / 题面 / 描述 / 必答 / 选项 / 校验 / 矩阵列」，带 UTF-8 BOM。

## 三、修复

- `QuestionForm` 小游戏包加载后直接读 `response.packs.length`；接口形状异常时
  整张属性面板崩溃、ErrorBoundary 把编辑器替换成错误页。已加数组兜底。
- 大厅有封面/无封面混排时卡片高度与底部按钮不齐；封面失效时媒体区留空。
  已改为统一媒体区 + 兜底渐变。
- 搜索替换在「大小写不敏感且只改大小写」时会整批禁用；现在只提交真正变化的命中。
