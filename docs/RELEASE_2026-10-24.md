## 一、面向参与者（可直接转发到社群）

### 🎨 全站换装「暗金」

- 平台默认主题从浅色换成**暗金**：近黑页底（`#0f0e17`）+ 深夜蓝卡面（`#1a1a2e`）
  - 金色主色（`#d4a574`），配亮金→深金渐变按钮和一层极淡的金色环境辉光。
    色值取自参照站 foxsir.top 的线上样式实测。
- 桌面端的大标题换**衬线字体**（Georgia/宋体系），更有「会所刊物」的气质；
  正文仍是无衬线，不影响阅读。
- 卡片悬停有金色辉光浮起；所有动效统一 0.18–0.4s `cubic-bezier(0.4,0,0.2,1)`。
- 深色偏好不受影响：金色文字对深底的对比度实测 **8.61:1**（无障碍 AA 线是 4.5:1）。

### 🌗 主题收敛为三套：暗金 / 暗色 / 明亮

- 原来的 8 套 daisyUI 预设（深蓝夜、黑金奢华、复古纸张、粉彩、霓虹、纯黑…）
  收敛为 **暗金（默认）、暗色、明亮** 三套；「跟随系统」选项移除。
- **老选择自动迁移，不用清缓存**：

| 你之前选的                 | 现在会是 |
| -------------------------- | -------- |
| 黑金奢华 / 纯黑 / 跟随系统 | 暗金     |
| 深蓝夜 / 霓虹              | 暗色     |
| 复古纸张 / 粉彩            | 明亮     |

- 问卷作者用旧预设发布的问卷同样按这张表迁移，显示意图不变。

### 🖥️ 桌面端有了顶栏导航

- 屏幕 ≥1000px 时，底部导航栏升到**顶部固定栏**（foxsir 式），内容列宽对齐
  1200px；**手机端保持底部导航不变**——主要受众在 Telegram 内嵌浏览器里，
  拇指热区不受影响。
- 问卷列表页桌面端从「手机壳投屏」变成真正的三列网格。

### 🧭 图标全面矢量化

- 约 50 处结构性 emoji（页签的 🏛🌳📜🏆、道具的 🎫⚡🛡、金币 🪙、排名奖牌
  🥇🥈🥉 等）全部换成 lucide 矢量图标：跨平台渲染一致、跟随主题变色。
- 排行榜前三名改为金/浅金/灰的数字圆徽，和主题色阶同源。

### ⏳ 加载不再是干等一行字

- 问卷列表和广场的首屏加载从「加载中…」一行字换成**结构骨架屏**
  （卡片形状的呼吸块），慢网络下能立刻看出页面结构。

### 🪙 金币卡不再「金里透青」

- 「我的金币」余额卡原来是 indigo→青色的硬编码渐变，换主题时会撞色；
  现在跟随主题（暗金下是亮金→深金渐变 + 深色数字），余额数字用等宽数字
  排版，跳动时不抖动。

### 🪪 认证卡生成器同步换装

- `/cert/` 默认外观与全站一致（暗金），和问卷页共用的主题选择也收敛为三套。

## 二、面向创作者与运营

- **管理端同步三套主题**（设置 → 界面外观），默认暗金；旧主题偏好同样自动迁移。
- **问卷级主题预设收敛**：编辑器「问卷主题」选择器只出三套；服务端白名单
  （`src/survey/theme.ts`）在读取与保存时把旧 id 归一到最近似主题——
  存量数据不改写，展示意图不变。
- 主题色板由 `admin/src/index.css` 的 `[data-theme="foxgold"]` 块单点定义，
  换色只动一处。

## 三、修复项

1. **主题选择抽屉被底栏盖住**（z-index 30 < 40）：在部分机型上「明亮/暗色」
   按钮点不到。已提到 z-50。
2. **金币余额卡对比度**：暗金下原渐变配白字仅约 3:1，现为主题化渐变配
   主题前景色（≈8:1）。
3. **剧情打字机文本键盘不可达**：跳过逐字动画只有点击一条路，补上
   Tab 聚焦 + 回车/空格触发。
4. **问卷密码门输入框**补 `autocomplete="off"`，避免密码管理器把访问密码
   存成站点密码。
5. **认证卡页「跟随系统」残留**：移除后系统深浅色切换不再触发无效换肤。
6. **CI 格式门禁被本地缓存卡死**：`.prettierignore` 补 `.mimosa/`
   （助手插件的本地状态文件，与源码无关）。
7. **上线后部分浏览器认证卡页停留在旧版**（旧 indigo 配色、投稿提示
   「知道了」点不动）：PWA service worker 对**不带内容哈希的稳定文件名**
   （`/cert/styles.css`、`/cert/app.js` 等）采用 cache-first 永不回源，
   部署再多次这些浏览器也只吃旧缓存。已改为：仅 `/assets/**`（文件名带
   哈希、内容变名字变）保持 cache-first，其余静态资源网络优先、缓存离线
   兜底；缓存版本 v2→v3，新 worker 激活时自动清掉全部旧缓存。受影响的
   浏览器**刷新一两次**即恢复。

## 四、技术变更

- **foxgold 主题**：自定义 daisyUI 5 主题块（完整变量契约），并复刻
  `:is(:root, :root:has(...))` 选择器模式对冲 light 主题 `:root` 的特异性
  （(0,4,1)），否则 `[data-theme="foxgold"]` 会被压住——这是本次最隐蔽的坑。
- **`--fx-*` 设计 token**：统一缓动曲线/时长、衬线字体栈、圆角四档
  （10/16/20/40）、辉光阴影两档 + 深投影；各主题可覆盖。
- **遗留 id 迁移**在四处同步：`admin/src/theme.ts`、
  `admin/src/survey/theme-ui.tsx`、Worker 端 `src/survey/theme.ts`（含单测）、
  `cert/app.js`。
- **两个 HTML 入口的 boot 脚本**默认 `foxgold`，首屏不闪错色；`theme-color`
  meta 跟随更新。
- **桌面顶栏让位**用 `body:has(nav[aria-label="主导航"])` 的透明 border-top
  一条规则实现，不逐屏加 padding。
- `transition-all` 全部改为列明属性（transform/box-shadow/color 等）；
  导航与图标按钮补 `focus-visible` 焦点环。
- daisyUI 主题导入从 8 套减到 2 套 + 自定义 foxgold，CSS 体积下降约 3KB。

## 五、已知限制

- **衬线标题用的是系统字体栈**（Georgia/宋体系），未引入 webfont；
  token 已就绪，后续想上 Noto Serif SC 子集只需改 `--fx-font-serif` 一个值。
- **成就图标仍是 emoji**：它们存在服务端成就定义里，属于内容而非界面，未动。
- 桌面各屏容器宽度未完全统一（列表页 1200px，广场/挑战仍为原宽度居中），
  观感已协调，后续可逐屏放宽。
- 树洞弹层的 `autoFocus` 保留（移除会改变移动端唤起键盘的习惯）。
- 第二次增量发布的版本号未记录（部署 API 瞬时不可达；已通过线上资源哈希
  `survey-BvUDBzsA.js` 与本地构建一致来确认生效）。
