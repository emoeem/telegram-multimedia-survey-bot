## 1. 一句话定位

**它是一套 Telegram + Web 双端的「问卷 → 个人报告」平台，不是普通的 Telegram 机器人。**

用户从 TG 点一下就能进入手机优先的网页答题、上传图片、拿到一份属于自己的图文报告；创作者有一套完整的可视化编辑器；运营方有一个 25 页的网页后台。整套系统跑在 Cloudflare 全球边缘，**没有服务器、没有 Docker、没有运维**。

### 它适合拿来做什么

| 场景 | 说明 |
|---|---|
| 人格测评 / 心理测试 | 维度计分引擎 + 多结局 + 分享卡 |
| 互动小说 / 剧情问卷 | 剧情 Flag、分支跳转、视觉小说模式、连载书架 |
| 兴趣社群问卷 | 树洞广场、展示区、个人画像、朋友互测 |
| 品牌 / 活动表单 | 14 种题型、媒体收集、PDF / Forms / Word 多源导入 |
| 私域内容变现 | 金币经济、逐章解锁、抽卡收藏 |
| 对外交付（加盟 / 客制） | 一条命令部署客户独立实例 + 授权码体系 |

## 3. 系统架构

```
                ┌──────────────┐        ┌──────────────┐
   国内用户 ──▶ │ emoemok.top  │        │  emoe.eu.cc  │ ◀── 境外用户
                │ (Vercel 中继)│        │(CF 自定义域) │
                └──────┬───────┘        └──────┬───────┘
                       └──────────┬────────────┘
                                  ▼
                    ┌─────────────────────────────┐
   Telegram ───────▶│   单个 Cloudflare Worker     │◀─── /admin 后台
   (webhook 指         │  Hono 路由 + 中间件         │
    workers.dev)      └───┬───────┬───────┬───────┘
                          │       │       │
                   ┌──────▼──┐ ┌──▼───┐ ┌─▼──────────┐
                   │   D1    │ │  KV  │ │ Durable    │
                   │ 87 迁移 │ │ ×2   │ │ Objects ×3 │
                   └─────────┘ └──────┘ └────────────┘
                          │
                   ┌──────▼──────────┐   ┌──────────────────┐
                   │ Queues（异步）   │   │ Browser Rendering│
                   │ 报告/PDF/导入    │   │ PDF / 图片渲染    │
                   └─────────────────┘   └──────────────────┘
```

**关键设计**

- **域名与 webhook 解耦**：用户拿到的所有链接由 `PUBLIC_ORIGIN` 钳死到国内可达域名；Telegram webhook 故意仍指 `workers.dev` —— 这样自定义域 DNS 出任何问题都不影响收消息。
- **单 Worker 多入口**：`/s`（填写）、`/me`、`/plaza`、`/showcase`、`/cert/`、`/admin`、`/api/*`、`/service/*`、Telegram webhook 全部由一个 Worker 的 Hono 路由分发。
- **异步优先**：报告生成、PDF 渲染、批量导入、导出全部走 Queues + Durable Object 驱动，不阻塞请求。

## 4. 填写者端（读者 / 用户）

### 4.1 答题

- 手机优先的 Web 填写页，**14 种作答题型**：单选、多选、单行文本、长文本、数字、是非、评分、矩阵、日期、时间、图片、视频、音频、文件；另有 `note` 叙述节点（只展示内容、不收集答案，可被跳题规则指向）
- **分页**、进度条、**断点续填**、作答后修改
- **题目级跳转**、**答案级跳转**（选项决定下一题）
- 访问控制三档：公开 / 访问密码 / **金币解锁**（作者显式开启，缺省仍免费）
- 媒体题：图片 JPEG/PNG/WebP，单张 ≤10MB、整卷 ≤50MB；草稿媒体 7 天 TTL，**提交后转存长效**，报告不会 7 天后变空图
- 身份三态：邮箱注册登录 / Telegram 身份自动识别 / 匿名访客；登录后**同浏览器匿名历史答卷自动并入账号**

### 4.2 报告

- 每份答卷生成**属于填写者本人**的报告，与创作者统计报告严格分离
- 四端同源输出：网页报告 / PDF（图片压至 ≤1200px，目标 ≤15MB）/ 分享图 / Telegram 私人频道归档
- 系统先判断问卷语义（个人档案 / 测评 / 偏好画像 / 普通问卷 / 普通表单），**不会把人名、身高、照片当成「人格分数」**；只有作者显式配置结果规则时才做维度计算
- **9 套报告模板**：`classic`、`transcript`、`magazine-dark`、`data`、`identity`、`art-archive`、`magazine`、`minimal`、`gallery`

**结局与分享**

| 能力 | 说明 |
|---|---|
| 结局分享卡 | 只公开结局名与卷名，**任何答案都不出现在卡上**；链接永久有效、可随时撤销；18+ 问卷只出含蓄 teaser |
| 结局图鉴 | 多结局问卷显示「🗺️ 结局图鉴 2/4」，未解锁显示「？？？结局」 |
| 系列书架 | 连载按系列聚合，显示章节数、阅读进度、续读入口；关注后新章自动通知（绑定 TG 的还收私信） |
| 朋友互测 | 把某份答卷设为「答案钥匙」，他人报告显示默契得分（钥匙答案永不下发） |

### 4.3 互动小说 / 视觉小说模式

- 作者开启 VN 模式后：**场景图铺满全屏、剧情逐字打出、叙事卡变带名牌的对话框**，像读一部互动小说
- 进度条按实际走过的剧情路线计算，分支下不跳变

### 4.4 社区

| 模块 | 能力 |
|---|---|
| 树洞 / 广场 | 发帖、评论、配图、话题分类、举报；**网页端可直发**（不必走 TG） |
| 展示区 | 「一屏一人」沉浸式人物 / 作品页，每页可单独分享；支持画廊多图与游标翻页 |
| 我的 | 身份卡、成就墙、报告列表、通知中心、偏好设置、个人画像 |

### 4.5 金币经济（完整闭环）

- **签到**：阶梯奖励（默认 1/3/7 天 → 5/8/15），日界按服务端 UTC+8 计算，**不信任客户端时钟**
- **挑战**：进度全部由服务端按真实记录计算（完成问卷数、签到连续、投稿通过、抽卡次数、发帖数），客户端不能上报进度；领取时重算
- **解锁问卷**：动态定价 `clamp(round(base × (1 + hot·ln(1+近30天完成量)) × quality))`；涨价不重复收费，解锁永久有效
- **报告抽卡**：奖池来自**审核通过的投稿**，绝无自动收集；奖池有**版本快照**，可事后审计「当时的概率」
- **投稿生态**：投稿 → 审核 → 入池，要求非匿名身份（问责）
- **账务三层保险**：D1 batch 隐式事务 + 余额守卫 `balance >= ?` + `idempotency_key` 唯一约束 + `CHECK(balance >= 0)`

### 4.6 趣味认证卡生成器（`/cert`）

- **纯前端 Canvas 渲染，零后端依赖，照片与勾选内容不上传服务器**
- **26 种版式**，分三组：
  - **证件样式（10 种，拟真）**：身份证、学生证、工牌、驾驶证、结婚证、就诊卡、会员卡、准考证、宠物证、荣誉证书。照真证件的字段排（姓名 / 性别 / 出生 / 住址 / 公民身份号码），带防伪底纹、微缩文字、金属芯片、全息标、钢印、机读码；18 位号码末位按 GB 11643 算校验码，出生日期与考场座位由编号**确定性**派生
  - **创意版式（13 种）**：资格证、环绕词云、混乱词云、印章满屏、宾果表、化验单、小票、狗牌、SSR 卡牌、成分表、通缉令、拍立得照片墙、印样联片
  - **成人向证件（3 种，18+ 后出现）**：认主契约（勾选词条逐条列为条款 + 盖章手印）、畜籍证、识别卡。**未确认 18+ 时这 3 项不进 DOM**，存档或分享链接带着它们会自动回退到普通版式
- **比例适配不拉伸证件**：证件按真实长宽比居中摆在台面上，下方接认证项目 / 等级 / 百分比 / 二维码
- **5 种画幅**：1:1 / 4:5 / 3:4 / 9:16 / 长图
- **8 套中性主题**：打工人、猫奴、程序员、咖啡、玩家、健身、美食、熬夜（各含 3 组标签库 + 等级称号区间）
- **8 套 UI 调色板**：与问卷填写页 daisyUI 主题同源（同源 localStorage 共享，两边观感一致）
- **成人词库包**：19 个板块 / 1,050 条词 / 9 档等级，**未点「我已满 18 岁」前页面里不存在任何一条成人词条**（动态注入）
- 评分按主题切换两套模型；成人档带性别感知（切换后重算强度、隐藏异性词、板块徽章）
- **分享链接 v2**：`#s=base64url(...)` 带上勾选 / 性别 / 强度 / 姓名 / 主题 / 版式 / 画幅，对方打开即还原同一张卡；内置二维码
- **单文件离线版**：微信里直接打开可用（「← 首页」自动改写为绝对地址）

## 5. 创作者端（编辑器）

### 5.1 编辑器

- 结构树 + 搜索 + 搜索结果**批量设置必答 / 选填**
- 拖拽排序、分页管理、题型切换、题目 / 选项复制
- **undo / redo、autosave、stale detection、409 并发保护**（两人同改不会互相覆盖）
- 题面与选项媒体管理
- 发布前检查 + 主题面板（含 VN 模式开关）
- **已存在答卷的问卷自动进入结构保护** —— 不允许改出会破坏历史数据语义的操作

### 5.2 版本管理

- `survey_versions` 快照，答卷绑定提交时的版本
- 版本列表、增删改 **diff 对比**、一键恢复为新草稿

### 5.3 结果引擎 2.0

- 定义评分维度、维度上下限与单位、参与题目、选项分值（多选逐项计分）
- 定义结果类型、总分区间、标题 / 副标题 / 描述 / 标签 / 图片
- **实时结果设计器**：模拟答案不写库，即时显示每个维度得分、总分、命中结果、区间与命中原因；未覆盖会直接提示

### 5.4 剧情引擎

- **选项命中 Flag**（flag 名 + 分值，可为负）
- **Flag 门槛跳转**（做好感路线、真结局锁定）
- 与既有选项跳转、历史答案跳转**完全兼容、互不覆盖**
- Flag 由已保存答案**确定性重放**，中途退出再续答路线不丢

### 5.5 试玩

- 编辑器内「试玩」：从任意节点出发，**用与真实玩家完全一致的跳转规则**走一遍
- 底部显示走过的节点足迹，可回退、看终局统计

### 5.6 导入（多源）

| 来源 | 说明 |
|---|---|
| survey JSON | 原生格式 |
| PDF | 结构化抽取（含数值 / 置信度） |
| Microsoft Forms | 官方导出格式 |
| Zoho Forms | 官方导出格式 |
| Word / OneDrive / SharePoint | 文档抽取 |
| 直接 URL | PDF / JSON 远程拉取 |

导入带分页、置信度、结构化 issue、自动修复、导入前后校验、**同名问卷重复检测**。

### 5.7 导出

CSV / XLSX / JSON / ZIP / PDF；队列异步执行，完成通知。

### 5.8 连载与变现

- 系列（一部作品 = 多个章节）+ 章节金币解锁天然支持逐章付费
- **结局收集奖池一键生成**（结果设计里的多结局直接生成抽卡池，默认草稿态）
- 18+ 分级开关（作者自声明，运营方审核）

## 8. 工程与可靠性

1. **单一数据源四端输出**
   `ReportViewModel → ReportTemplateSpec → Web / PDF / Image / TG 归档`，模板只改版式不改计算。

2. **结构化归档 ZIP**
   `00-index.json` + `01-report / 02-answers / 03-attachments / 04-profile / 05-result-assets`；超阈值自动降级为 PDF + 图片逐项发送。

3. **三重幂等**
   Telegram `update_id` 去重（`processing` 状态可超时接管）、报告投递 `delivery_id` 幂等键（退避 1m → 5m → 15m → 1h，最多 5 次）、金币 `idempotency_key`。

4. **D1 免费额度硬护栏（真实事故验证过）**
   2026-09-14 单日 **5,341,161 rows read**（孤儿媒体扫描走全表）。修复后：补索引 + 执行前索引守卫 + `MAINTENANCE_ROWS_READ_BUDGET = 500,000` 超预算立即中断 + 请求级行读指标 + KV 版本化缓存。之后稳定在 10 万级。

5. **观测**
   每请求输出 route / method / status / duration / D1 query / rows read / rows written / KV hit-miss / queue sends；并明确**不记录密码、token、完整答案、请求体**。

6. **前端分包**
   route-level `React.lazy`，ECharts 单独懒加载（1.13MB 不进首页）。

7. **视觉回归**
   20 路由 × 2 主题 × 2 viewport = 80 组组合。

8. **测试**
   165 个测试文件 / 1,010 个用例，覆盖规则引擎、幂等、计费、报告渲染、路由权限、E2E（Playwright 真浏览器）。

## 10. 局限与边界

| 限制 | 说明 |

## 11. 部署与运维

```bash
# 本地开发
pnpm install
pnpm dev                # wrangler dev + admin vite

# 构建与部署
pnpm build              # 编译 Worker + 构建 admin
pnpm deploy             # build:admin && wrangler deploy

# 数据库
pnpm migrate:local      # 本地 D1
pnpm migrate:remote     # 远端 D1

# 质量门禁
pnpm typecheck
pnpm test
pnpm lint
pnpm e2e
```

**运维成本**：零常驻进程、零容器、零 VPS；按请求计费，个人项目可落在免费额度内（靠第 8 节的额度护栏守住）。

### 12.5 可直接转发的简介

> 这是一个跑在 Cloudflare 边缘上的 **Telegram + Web 问卷与个人报告平台**，不是普通 Bot。填写者从 TG 点一下就能答题、传图、拿一份属于自己的图文报告（网页 / PDF / 分享卡三选一）；创作者有完整的可视化编辑器——14 种题型、结果维度引擎、剧情 Flag、可视化试玩、PDF / Forms / Word 多源导入、9 套报告模板、版本 diff 回滚；运营方有 25 页的网页后台，含分级管理、金币经济、审计日志。它还有互动小说模式、树洞广场、一屏一人的展示区、连载书架追更，以及一个纯前端的趣味认证卡生成器（26 种版式，含身份证 / 学生证 / 工牌 / 驾驶证 / 结婚证等拟真证件，照片不上传服务器）。
>
> 工程上：**零服务器、零 Docker、零运维**，约 9.4 万行代码、1,010 个自动化测试、87 个数据库迁移，幂等与成本护栏都经过真实事故验证，可一条命令为客户独立部署并配套授权码体系。


## 部署档位（free / paid / pro）

部署能力按 Cloudflare 绑定自动探测（`src/services/plan.service.ts`，原则与矩阵见
`CLOUDFLARE_PLAN_TIERS.md`），后台首页「部署能力」面板可见。R2/Stream/Images/
Browser/Queues 任一未绑定时，对应功能走等价降级路径（KV+TG 媒体、HTML 报告、
同步任务执行），**免费部署不缺按钮**。R2 部署的答卷媒体上限放宽为单文件
100MB / 总量 200MB。
答卷视频/音频在 Pro 部署（配置 `STREAM_ACCOUNT_ID`/`STREAM_API_TOKEN`）走
Cloudflare Stream 浏览器直传（转码 + HLS），免费部署保持经 Worker 的 20MB KV 路径；
认证卡成品图在配置 `IMAGES_*` 三项后旁路上传 Cloudflare Images（响应带可直链的
`imageUrl`）。
