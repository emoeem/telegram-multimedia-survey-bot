# Result Engine 2.0

## 目标

Participant Report 现在支持由问卷创建者定义确定性的结果规则，而不是仅依赖题目标题自动推断。

## 创建者配置

编辑器的「问卷设置」中提供「结果规则」面板：

- 创建评分维度，并设置最小/最大分。
- 把单选、多选、是非、评分题加入维度。
- 为每个选项定义分值。
- 创建最终结果类型，并设置总分区间。
- 配置结果标题、说明、标签和结果图片。
- 保存前由后端 Result Engine 校验 schema。

## 计算链路

`Answers → Dimension Scoring → Dimension Stats → Total Score → Result Type → Participant Report`

程序负责计算事实和匹配区间；报告模板只负责呈现。

## 兼容性

规则继续保存在 `survey_result_rule_sets.rules_json`，schemaVersion 保持为 1；新增 `dimensions` 和 `resultTypes` 字段属于同一 JSON schema 的向后兼容扩展。

没有修改历史 migration。没有引入新的后端服务或数据库。

## 安全

规则 JSON 仍经过 `parseResultRuleSet()` 严格校验，禁止危险路径和可执行表达式。创建者只能修改自己有权限管理的问卷。


## 实时结果预览 / 测试答案

编辑器的「结果设计器」现在包含实时调试面板。创建者把题目加入维度后，可以直接模拟选择题、评分题和多选题答案；预览不会写入真实答卷。

预览会即时展示：
- 每个维度当前得分 / 配置最大分；
- 所有维度合计分数与进度；
- 当前命中的结果类型及其分数区间；
- 结果标题、文案和标签；
- 「为什么匹配」：明确指出总分落入哪个结果区间；
- 未匹配结果时的覆盖范围提示。

结果区间新增结果时会以当前维度最大总分作为默认上限，避免多维度问卷仍默认使用 100 分造成配置错误。
