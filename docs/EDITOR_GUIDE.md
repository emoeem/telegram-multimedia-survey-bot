## 一、编辑器长什么样：三栏布局

打开编辑器后从左到右是三块：

| 区域                | 放什么                   | 能做什么                                                              |
| ------------------- | ------------------------ | --------------------------------------------------------------------- |
| **左栏 · 结构树**   | 这份问卷的全部分页和题目 | 新建分页、拖动/上移下移排序、搜索题目、复制/删除、进入试玩            |
| **中栏 · 题卡**     | 当前选中题目的编辑表单   | 改题干、描述、选项、分值、跳转、附件、必答                            |
| **右栏 · 问卷设置** | 全局设置                 | 标题描述、报告模板、结果设计器、结局奖池、金币解锁、匿名/18+/重复填写 |

顶部一条工具栏：返回详情、**撤销 / 重做**（Ctrl+Z / Ctrl+Shift+Z）、保存状态、**保存**、**发布**。

## 二、基本操作：保存 / 撤销 / 发布 / 锁定

- **自动保存 + 手动保存**：编辑过程中修改会先记在本地草稿，顶栏会显示未保存状态；点「保存」才写回服务器。离开页面前有未保存修改会先弹确认。
- **撤销 / 重做**：Ctrl+Z / Ctrl+Shift+Z（或点顶栏箭头），可以一步步回退。
- **草稿锁**：同一份问卷同一时间只有一个人能以编辑状态打开（防止两人互相覆盖）。如果你在另一台设备打开了同一份问卷，后打开的一边会被提示只读。
- **发布**：点「发布」后问卷进入**只读状态**——题目、选项、分值都不能再改（因为已经有人作答，改动会破坏历史答案的语义）。发布按钮在有未保存修改时是灰的，先保存才能发布。
- **改已经发布的问卷？** 题目本身锁死，但**设置类**（匿名、18+、金币解锁、结果规则的文案等）仍可在详情页/编辑器中调整；想大改题目就复制一份新问卷。
- **有答卷后**：连结果规则的分值也建议不动——改分值会让已生成的报告和新报告口径不一致。

## 三、结构树：分页、排序、搜索、批量设置

- **分页**：点结构树右上角「＋」新建分页。分页只影响答题者翻页节奏，**删除分页不会删除题目**（题目会回到不分页状态）。
- **排序**：每行右侧有上移/下移按钮；也支持拖拽。顺序就是答题者看到的顺序。
- **搜索**：结构树顶部的搜索框按题干过滤；搜出一批题后可以**批量设置必答/选填**（比如一键把所有「姓名」类题目设为选填）。
- **复制 / 删除**：题卡菜单里有复制题目（连选项一起复制）；删除题目会连同它的分值配置一起删。
- **试玩**：从任意一道题出发，按真实跳转逻辑走一遍（和玩家看到的完全同一套规则），走过的路径以足迹显示。改完分支剧情后**强烈建议试玩一次**再发布。

## 四、十四种题型 + 剧情文段，每种是什么意思

点「添加题目」后弹出的选择器分四组。每种题型一句话说明 + 使用要点：

### 剧情（不收集答案的叙述节点）

| 类型            | 是什么                                                                                                 | 什么时候用                                                                              |
| --------------- | ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| 📖 **剧情文段** | 一段展示给答题者看的故事文字，**不收集任何答案**；可以配插图。后面的题目选项可以把答题者跳转到不同文段 | 做互动小说/剧情卷的开场白、过场、分支场景。它就是「剧情片段」——不是题，是**故事的一页** |

剧情文段的写法：正文里空行即分段；答题者先读完这段，再继续后面的题目或分支。配上插图就是一页视觉小说。

### 选择类（可计分、可跳转）

| 类型     | 是什么                | 要点                                                             |
| -------- | --------------------- | ---------------------------------------------------------------- |
| **单选** | 多个选项选一个        | 每个选项可配分值（进结果维度）、可配「选择后跳转」               |
| **多选** | 同时选多个            | 支持逐项计分（选 3 项就按 3 项的分值累加）；每个选项同样可配跳转 |
| **是非** | 是 / 否 二选一        | 本质是两个选项的单选，分值与跳转同单选                           |
| **评分** | 星级评分（如 1–5 星） | 每个星级是一个「选项」，可分别配分值与跳转                       |
| **矩阵** | 多行 × 多列的网格     | 行=选项，列在题目设置里维护；适合「对以下每件事打分」式问题      |

### 填写类

| 类型                | 是什么                 |
| ------------------- | ---------------------- |
| **单行文本**        | 一行文字（昵称、代号） |
| **多行文本**        | 长文本（感想、故事）   |
| **数字**            | 数字输入               |
| **日期** / **时间** | 日期选择 / 时间选择    |

### 上传类（由答题者上传）

| 类型                          | 是什么                     |
| ----------------------------- | -------------------------- |
| **图片 / 视频 / 音频 / 文件** | 作答者上传对应媒体作为答案 |

> 除上传类外，**题干本身也能配附件**（图/视频/音频/文件），选择题的**每个选项**也可以带图——做「看图选人」「选项带立绘」的卷子靠这个。

## 五、分支与剧情玩法：选项跳转 + 剧情文段 + 试玩

这是做互动内容的核心机制，三步：

1. **插入剧情文段**：点「添加剧情文段」，写一段场景（可配图）。比如：
   - 文段 A：「你推开了左边的门……」
   - 文段 B：「你走向了右边的楼梯……」
2. **给选择题的选项配「选择后跳转」**：单选/是非/评分的每个选项都能设置跳转目标——可以是**某道题**，也可以是**某个剧情文段**。
   - 例：「你选择走哪边？」→ 选项「左边」跳转到文段 A，选项「右边」跳转到文段 B。
3. **试玩验证**：结构树里选任意节点开始试玩，确认每条分支走得通、不会走进死胡同。

要点：

- 跳转**只向前不回头**（不会形成环）。
- 没配跳转的选项就按正常顺序走下一题。
- 剧情文段不影响计分——它是纯叙事。

## 六、结果设计器：评分维度、最终结果、实时预览

右栏「结果设计器」决定**答题者交卷后看到什么结果**。整条计算链是：

```text
答题 → 题目计分 → 维度得分 → 总分 → 落进哪个结果区间 → 展示那个结果
```

### 1. 评分维度

- 点「**＋ 添加维度**」新建一个维度（如「独立性」「外向度」）。
- 在维度里**添加影响题**：把选择题（单选/是非/评分/多选）加进来。
- 给这道题的**每个选项配分值**：比如「独自旅行」+5、「跟团出行」+1。
- 设维度的**最小分 / 最大分**（用于预览里的百分比和报告中的量表展示）。

一个维度 = 被测的一个侧面。可以做单维度（只有总分），也可以做多维度（如 4 个人格侧面）。

### 2. 最终结果（结果类型）

点「**＋ 添加结果**」定义一个结局。每个结局有：

| 字段                    | 含义                                                        |
| ----------------------- | ----------------------------------------------------------- |
| **结果名称**            | 内部名（如「探索型」）                                      |
| **ID**                  | 稳定标识，生成结局奖池 / 报告引用用；建好后别改             |
| **最低总分 / 最高总分** | 总分落在 `[最低, 最高]` 区间即命中该结果                    |
| **结果标题**            | 答题者看到的结局大标题                                      |
| **结果文案**            | 结局正文描述                                                |
| **标签**                | 逗号分隔的小标签（如 `冒险, 独立`），会出现在报告与结局卡上 |
| **结果图片 URL**        | 结局配图（外链图片地址）                                    |

命中规则：**按所有维度加起来的总分**匹配区间。区间建议首尾相接铺满整个分值范围（0–20、21–40……），否则会出现「没有匹配结果」。

### 3. 实时结果预览（右侧）

- 在左边把题目加入维度后，右侧会出现**可模拟的测试答案**：点选每个题的选项，立刻算出：
  - 每个维度的得分（如 `独立性 8/10`）；
  - 最终总分；
  - 命中的结果 + 命中原因（「总分 13 落在探索型区间」）。
- 测试答案**只用于调试，不会写入真实答卷**；「清空答案」一键归零。
- 如果显示「没有匹配结果 / 当前总分不在任何结果区间内」，说明区间没铺满，回去补。

## 七、结局收集奖池：把结局变成抽卡内容

「结局收集奖池」是结果设计器的延伸玩法：

- 点「**生成结局奖池**」：把你定义的每个**结果**自动做成一张**结局卡**，进入全站抽奖中心的奖池（草稿态）。
- 读者完成你的问卷后，可以花金币去**抽奖中心**抽结局卡——抽到自己没抽到的结局，形成「为了集齐结局再答一次」的复玩动力。
- 生成后到 **管理后台 → 社区 → 抽卡** 调整每张卡的价格与上下架。
- 想改结局内容：回结果设计器改「结果类型」的字段；奖池内容重新生成即可。

## 八、问卷设置逐项说明

右栏「问卷设置」从上到下：

| 设置             | 作用                                                                                                        | 什么时候开                                                                        |
| ---------------- | ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| **标题 / 描述**  | 问卷名 + 给答题者的整体说明                                                                                 | —                                                                                 |
| **报告模板**     | 选择答卷报告的版式（不同模板=不同排版与视觉主题，不改变计算）                                               | 想换报告外观时                                                                    |
| **金币解锁**     | 开启后答题者需花金币解锁本问卷；可选**自动定价**（按热度算）或手动设**基础价格**；「固定价格 0 = 限时免费」 | 想把问卷做成付费内容时。注意：金币解锁与「密码保护」互相独立                      |
| **结果设计器**   | 见第六节                                                                                                    | 测评类问卷必配                                                                    |
| **结局收集奖池** | 见第七节                                                                                                    | 想做结局收集玩法时                                                                |
| **匿名填写**     | 开启后**不记录答题者的 Telegram 身份**                                                                      | 想让答卷完全匿名的问卷                                                            |
| **18+ 内容**     | 开启后问卷**只在目录/广场/展示区对已确认年龄的访问者可见**，分享出去的预览卡走安全版（不泄露标题内容）      | 内容尺度大或仅限成人的问卷                                                        |
| **允许重复填写** | 同一用户可多次提交；配合「每人填写上限（0=不限）」控制次数                                                  | 结局收集类问卷通常开启（为了抽齐结局再答）                                        |
| **密码保护**     | 给问卷加访问口令，答题者需输入密码才能开始                                                                  | 目前在 **Telegram Bot** 里设置；Web 端问卷详情页可查看「密码保护：已启用/未启用」 |

## 九、三个完整例子

### 例 1：性格测评卷（多维度 + 区间结果）

1. 出 8 道单选，每题 4 个选项；
2. 结果设计器建 2 个维度：「理性」收 Q1/Q3/Q5，「感性」收 Q2/Q4/Q6，每选项配 1–5 分，最大分设好；
3. 添加 4 个结果：总分 8–13「冷静分析者」、14–19「平衡者」、20–25「共情者」、26–32「热忱理想者」，各自写标题/文案/标签；
4. 右侧预览点一遍答案，确认每个区间都能命中；
5. 设置里开「允许重复填写」，生成结局奖池，上架结局卡。

### 例 2：分支剧情卷（剧情文段 + 选项跳转）

1. 开头放一个剧情文段做开场；
2. 一道单选「你的行动？」，每个选项跳到不同文段；
3. 每个文段后面接各自的后续题目与文段，层层推进；
4. 结尾按剧情路线配一个结果类型（比如走「左线」的都能到「灯塔结局」——用一道收尾计分题把不同路线映到不同总分区间）；
5. 试玩每条分支，发布。

### 例 3：投稿收集卷（上传题 + 匿名）

1. 题型用「多行文本」+「图片上传」收集内容；
2. 设置里开「匿名填写」（不留 TG 身份）；
3. 视内容尺度决定是否开「18+」；
4. 不配结果维度——这类卷子不需要结果页。

## 十、常见问题

**Q：剧情文段和题目描述有什么区别？**
题目描述是某道题的补充说明（跟着题走）；剧情文段是独立的叙事页（不依附任何题目，可被跳转当作场景）。

**Q：为什么发布按钮点不了？**
有未保存的修改——先保存。发布后问卷只读，这是为了保护已产生的答卷数据。

**Q：改了选项文字会影响旧答卷吗？**
改文字安全；**删除/重建选项**会切断旧答卷与选项的关联，尽量避免。有答卷后编辑器也会锁定大部分改动。

**Q：结果区间要怎么铺？**
从 0 开始按连续区间写到最大分（如 0–10、11–20、21–30）。区间之间留空隙 = 那段分数的人看不到结果。

**Q：矩阵题的列能随便改顺序吗？**
谨慎——矩阵答案按列的位置存储，改列顺序会改变历史答案的含义。问卷发布前定好列。

**Q：结局卡的价格在哪改？**
生成奖池后到「管理后台 → 社区 → 抽卡」调价与上架。

**Q：怎么让别人填？**
详情页复制问卷链接 `/s/:id`（可分享到 Telegram/微信）；开了金币解锁的问卷，答题者会先看到解锁页。
